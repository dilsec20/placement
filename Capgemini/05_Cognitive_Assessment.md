## 🎮 Game 1: Motion Challenge

### What It Is
- You have a **ball** that must reach a **hole** on a grid
- You move the ball using directional controls (up/down/left/right)
- Obstacles block certain paths
- Goal: Reach the hole in **fewest moves** possible

### Strategy

```
Step 1: SCAN the entire grid before making your first move
Step 2: PLAN the shortest path mentally (count moves)
Step 3: Avoid dead ends — look for clear corridors
Step 4: Move deliberately — each wrong move costs
Step 5: Think 2-3 moves ahead (like chess)
```

### Practice Tips
```
🎯 Play maze/puzzle games daily (2048, Sokoban, Rush Hour)
🎯 Practice path-finding on paper grids
🎯 Focus on PLANNING before ACTING
🎯 Time yourself to build speed without sacrificing accuracy
```

### Example Layout
```
┌───┬───┬───┬───┬───┐
│ 🔵│   │ ██│   │   │
├───┼───┼───┼───┼───┤
│   │ ██│   │   │ ██│
├───┼───┼───┼───┼───┤
│   │   │   │ ██│   │
├───┼───┼───┼───┼───┤
│ ██│   │ ██│   │   │
├───┼───┼───┼───┼───┤

Optimal path: Down→Down→Right→Right→Down→Down→Right→Right
```

## 🎮 Game 2: Grid Challenge

### What It Is
- Two grids are displayed side by side
- You must quickly determine if they are **IDENTICAL** or **DIFFERENT**
- Sometimes you must remember a grid and compare it with a new one shown later
- Tests: **Focus, Memory, Pattern Recognition, Multitasking**

### Strategy

```
Step 1: Focus on the CENTER of each grid first
Step 2: Scan systematically: top-left → top-right → bottom-left → bottom-right
Step 3: Look for color differences, missing dots, or shifted positions
Step 4: Don't overthink — your first instinct is usually correct
Step 5: If unsure, look at CORNERS (differences often hide there)
```

### Practice Tips
```
🎯 Play "Spot the Difference" games online
🎯 Practice visual memory exercises (memorize a pattern, then recall)
🎯 Use flashcard apps with visual patterns
🎯 Train to scan systematically (don't just "look" — actively compare)
```

### Example
```
Grid A:        Grid B:
● ○ ● ○       ● ○ ● ○
○ ● ○ ●       ○ ● ○ ●
● ○ ● ○       ● ○ ○ ○  ← Difference here (● → ○)
○ ● ○ ●       ○ ● ○ ●

Answer: DIFFERENT (Row 3, Col 3)
```

## 🎮 Game 3: Deductive Reasoning (Geo-Sudo)

### What It Is
- Similar to **Sudoku** but with shapes/symbols instead of numbers
- Fill a grid so that no symbol repeats in any row or column
- Tests: **Logical deduction, Process of elimination**

### Strategy

```
Step 1: Start with rows/columns that have the MOST filled cells
Step 2: Use ELIMINATION — what CAN'T go in this cell?
Step 3: If stuck, look for "naked pairs" (two cells that must contain two specific symbols)
Step 4: Work systematically, don't guess randomly
```

### Example (4×4 with shapes: ■ ▲ ● ★)
```
Before:          After:
■ _ ● _          ■ ▲ ● ★
_ ● _ ■    →    ★ ● ▲ ■
● _ ■ _          ● ★ ■ ▲
_ ■ _ ●          ▲ ■ ★ ●

Rule: Each shape appears exactly ONCE per row and column
```

## 🎮 Game 4: Switch Challenge

### What It Is
- You are shown a sequence of shapes/patterns
- A "switch" (rule/code) transforms the input into output
- You must identify the **rule** and predict the output for a new input
- Tests: **Pattern recognition, Logical mapping**

### Strategy

```
Step 1: Compare input and output carefully
Step 2: Look for: rotations, reflections, color changes, position swaps
Step 3: Test your hypothesis with multiple examples
Step 4: Apply the identified rule to the new input
```

### Example
```
Input: ▲ ■ ●    →    Output: ● ■ ▲     (Rule: REVERSE the order)
Input: ★ ▲ ■    →    Output: ?          (Answer: ■ ▲ ★)

Input: 🔴🔵🟢   →    Output: 🔵🟢🔴    (Rule: ROTATE left by 1)
Input: 🟡🔴🔵   →    Output: ?          (Answer: 🔴🔵🟡)
```

## 🎮 Game 5: Inductive Reasoning

### What It Is
- Series of figures showing a pattern progression
- Identify the rule and predict the next figure
- Tests: **Pattern recognition, Abstract reasoning**

### Common Pattern Types

| Pattern | How to Spot |
|---------|-------------|
| Rotation | Shape rotates 45°/90° each step |
| Addition | New element added each step |
| Subtraction | Element removed each step |
| Color change | Colors cycle (red→blue→green→red) |
| Size change | Element grows/shrinks |
| Reflection | Mirror image alternation |
| Number pattern | Count of elements follows a sequence |

### Example
```
Step 1: △        (triangle, 3 sides)
Step 2: □        (square, 4 sides)
Step 3: ⬠        (pentagon, 5 sides)
Step 4: ?        (hexagon, 6 sides)

Rule: Number of sides increases by 1
```

## 📝 Logical Reasoning Section

### Type 1: Number Series

**Q1.** 2, 6, 12, 20, 30, ?
**Answer: 42** (differences: 4, 6, 8, 10, 12 → increasing by 2)

**Q2.** 1, 1, 2, 3, 5, 8, 13, ?
**Answer: 21** (Fibonacci: each = sum of previous two)

**Q3.** 3, 9, 27, 81, ?
**Answer: 243** (×3 each time: 3¹, 3², 3³, 3⁴, 3⁵)

**Q4.** 1, 4, 9, 16, 25, ?
**Answer: 36** (Perfect squares: 1², 2², 3², 4², 5², 6²)

**Q5.** 2, 3, 5, 7, 11, 13, ?
**Answer: 17** (Prime numbers)

---

### Type 2: Letter/Alphabet Series

**Q6.** A, C, E, G, ?
**Answer: I** (skip 1 letter: +2 each)

**Q7.** Z, X, V, T, ?
**Answer: R** (reverse skip 1: -2 each)

**Q8.** AZ, BY, CX, DW, ?
**Answer: EV** (first: A→B→C→D→E, second: Z→Y→X→W→V)

---

### Type 3: Coding-Decoding

**Q9.** If CAT = 24, DOG = 26, then BAT = ?
**Answer: 23** (C=3,A=1,T=20 → 24. B=2,A=1,T=20 → 23)

**Q10.** If APPLE = 50, then GRAPE = ?
**Answer: 50** (A=1,P=16,P=16,L=12,E=5 → 50. G=7,R=18,A=1,P=16,E=5 → 47... let me recalculate)
Actually: Different encoding possible. Focus on the pattern given.

### Type 4: Seating Arrangement

**Q11.** 6 people (A-F) sit in a row. B sits next to A. C sits at one end. D is not next to E. F sits between A and C. Find the arrangement.

```
Step 1: C is at one end → C _ _ _ _ _ or _ _ _ _ _ C
Step 2: F sits between A and C → C F A _ _ _ 
Step 3: B sits next to A → C F A B _ _
Step 4: D is not next to E → D and E separated
Step 5: C F A B D E or C F A B E D (check D not next to E)
        C F A B D E → D(pos5) next to E(pos6) ❌
        C F A B E D → E(pos5) not next to D(pos6)... wait, they ARE next to each other
        Actually: D not next to E means we need a gap.
        Try: C _ _ _ _ F A B (C at end, F between A and C) — 
        Hmm, let me use a clearer arrangement:
Answer: C F A B D E (where D at pos 5, E at pos 6... actually D IS next to E here)
Better: C F A B E D — but E-D are adjacent too. 
This shows why you need to carefully trace constraints!
```

> **Tip:** For these problems, draw the arrangement physically and test each constraint.

## 🎭 Behavioural Module

### What It Is
- Scenario-based questions about workplace behaviour
- No "right" answer — but some are better fits for Capgemini's culture
- Tests: Teamwork, adaptability, ownership, communication

### Sample Scenarios

**S1.** "Your team leader assigns you a task you've never done before. What do you do?"
- **Best:** "I'd research the topic, try to understand the basics, and then ask my team leader specific questions if I get stuck, rather than going back immediately to say I don't know how."

**S2.** "A teammate takes credit for your idea in a meeting. What do you do?"
- **Best:** "I'd speak to them privately after the meeting, explain my perspective calmly, and suggest we clarify contributions in the next meeting. I'd avoid confrontation in public."

**S3.** "You're behind on a deadline due to unforeseen issues. What do you do?"
- **Best:** "I'd inform my manager immediately about the delay and the reason, propose a revised timeline, and ask if any help or resources could be allocated to speed things up."

### Capgemini Values to Reflect

```
✅ Collaborative (team over individual)
✅ Proactive (act before asked)
✅ Accountable (own your mistakes)
✅ Client-focused (impact on customer)
✅ Growth-oriented (learning mindset)
✅ Honest & transparent (don't hide problems)
```
