## 🗓️ Preparation Timeline

### Week 1: English + AI Literacy (Stages 1 & 2)
- [ ] Practice English grammar, reading comprehension
- [ ] Speaking practice (45-90 second topics, email writing)
- [ ] Study AI/ML basics, Prompt Engineering, RAG concepts
- [ ] Learn LLM fundamentals, Responsible AI

### Week 2: Technical + Debugging (Stages 2 & 3)
- [ ] Master pseudocode tracing (arrays, loops, stacks)
- [ ] Practice DSA MCQs (OOPs, DBMS, SQL)
- [ ] Debug 50+ code snippets (Java/C++)
- [ ] Focus on common bug patterns

### Week 3: Coding + Cognitive (Stages 4 & 5)
- [ ] Solve 30+ LeetCode Easy/Medium (Arrays, Strings)
- [ ] Practice AI-assisted coding approach
- [ ] Play cognitive games daily (15-20 min)
- [ ] Mock full assessment simulation
