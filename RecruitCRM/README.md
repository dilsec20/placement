## 📋 Selection Process (4 Rounds)

```
Round 1: Online MCQ Test
├── Aptitude & Logical Reasoning
├── Core Java (Output Prediction, Syntax)
├── SQL Queries
└── DSA Concepts

Round 2: Online Coding Assessment
├── 2 Medium-Level Problems (60 min)
├── Focus: HashMap, Stack, Array patterns
└── Start brute-force → optimize

Round 3: Technical Interview
├── DSA Deep Dive (follow-up questions)
├── Project Discussion (Architecture, Design Choices)
├── REST API Design
├── SQL vs NoSQL
└── CS Fundamentals (OS, CN, DBMS)

Round 4: Founder/HR Interview
├── Culture Fit & Company Understanding
├── Long-term Career Goals
└── Communication Skills
```
