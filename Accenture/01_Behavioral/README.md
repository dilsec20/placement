## 📌 What is the Behavioral Assessment?

The Behavioral Assessment is a **psychometric personality test** designed to understand:
- Your work style and personality
- How you handle real-world professional situations
- Whether you fit Accenture's culture and values

It is **not a right/wrong test** — it measures your **behavioral traits** using validated psychometric frameworks.

## 📝 Question Formats

### Format 1: Likert Scale (Most Common)
Rate how much you agree with a statement:
```
"I prefer to plan my work thoroughly before starting."
  Strongly Disagree → Disagree → Neutral → Agree → Strongly Agree
```

### Format 2: Situational Judgment (SJT)
Choose what you WOULD do or SHOULD do:
```
"Your team is behind on a deadline. You would..."
  (a) Work extra hours alone
  (b) Ask manager for help
  (c) Reprioritize tasks with team
  (d) Inform stakeholders of delay
```

### Format 3: Ranking
Rank options from most to least like you:
```
When given a new project, I first:
  [Rank 1-4] Research the topic independently
  [Rank 1-4] Consult team members
  [Rank 1-4] Create a structured plan
  [Rank 1-4] Jump in and learn by doing
```

## ⚠️ Key Rules for Behavioral Assessment

| Rule | Why It Matters |
|------|----------------|
| **Be Consistent** | The test has trap questions — same situation worded differently |
| **Don't Fake** | Algorithms detect "socially desirable" over-answers |
| **Be Authentic** | Give answers that reflect your genuine personality |
| **Avoid Extremes** | Don't always pick "Strongly Agree/Disagree" for everything |
| **Think Professional** | Answer as if you're at work, not in casual life |

## 💡 Preparation Tips

1. **No studying needed** — Be yourself
2. **Read each question carefully** — Don't rush (you have 20 mins for 54 Qs)
3. **Consistency is KEY** — The same trait is tested multiple times
4. **Professional mindset** — Think "in a workplace" context
5. **Don't second-guess** — First instinct is usually best
