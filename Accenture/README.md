## 🏆 Preparation Strategy

### Week 1–2: Foundation
- [ ] Understand Pseudocode patterns — do 10 questions/day
- [ ] Learn Cloud, Networking, Security basics
- [ ] MS Office fundamentals

### Week 3–4: Core Practice
- [ ] Solve Coding problems daily (Arrays, Strings in C++)
- [ ] Practice gamified cognitive puzzles (brain-training apps)
- [ ] Communication — speak 10 mins daily in English

### Week 5–6: Final Revision
- [ ] Solve all PYQs in each section
- [ ] Mock test (full 175-min simulation)
- [ ] HR preparation using STAR method

## 💡 Key Tips

| Tip | Description |
|-----|-------------|
| **No Negative Marking** | Attempt ALL questions, never leave blank |
| **Pseudocode is KEY** | Most eliminated in Technical MCQ round |
| **Coding is Easy-Medium** | Focus on correctness, not complexity |
| **Be Consistent** | Behavioral test has consistency checks |
| **Speak Clearly** | Communication round is AI-graded |
| **Prepare Projects** | Technical interview heavily project-based |
