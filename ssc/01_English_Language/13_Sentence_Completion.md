## Introduction

Sentence Completion questions test your ability to choose the correct word, phrase, or clause to complete a sentence meaningfully and grammatically. Unlike Fill in the Blanks (which focuses on single words), sentence completion often involves choosing entire phrases or understanding complex sentence structures.

**Weightage in SSC CHSL Tier 1:**
- Questions: 1-2 out of 25
- Marks: 2 marks each

## Types of Sentence Completion Questions

### Type 1: Complete the Sentence (Choose best ending)
> "The teacher was so strict that ____"
> (a) the students loved her (b) nobody dared to misbehave ✅ (c) she was always late (d) exams were easy

### Type 2: Choose the Best Connector
> "_____ it was raining, we went for a walk."
> (a) Because (b) Although ✅ (c) So (d) And

### Type 3: Conditional Sentence Completion
> "If I had studied harder, I ____"
> (a) will pass (b) would pass (c) would have passed ✅ (d) had passed

### Type 4: Clause Matching
> "Not only is he intelligent ____"
> (a) and also hardworking (b) but also hardworking ✅ (c) also hardworking (d) as well as hardworking

## Grammar Rules for Sentence Completion

### 1. Conditional Sentences

| Type | If Clause | Main Clause | Example |
|------|-----------|-------------|---------|
| Type 0 | Present Simple | Present Simple | If you heat water, it boils. |
| Type 1 | Present Simple | will + V1 | If it rains, I will stay home. |
| Type 2 | Past Simple | would + V1 | If I were rich, I would travel. |
| Type 3 | Past Perfect | would have + V3 | If I had known, I would have come. |
| Mixed | Past Perfect | would + V1 | If I had studied, I would be successful now. |

```
Complete: "If she had left earlier, she ____"
Answer: would have caught the train ✅

Complete: "If I were you, I ____"
Answer: would not do this ✅

Complete: "If he works hard, he ____"
Answer: will succeed ✅
```

### 2. Correlative Conjunctions

| Pattern | Rule | Completion |
|---------|------|-----------|
| Not only...but also | Parallel structure | Not only is she smart but also hardworking |
| Either...or | One of two | Either you or I will go |
| Neither...nor | None of two | Neither Ram nor Shyam has come |
| Both...and | Two together | Both tea and coffee are available |
| Hardly/Scarcely...when | Inversion | Hardly had he arrived when it rained |
| No sooner...than | Inversion | No sooner did he come than it started raining |
| Whether...or | Choice | Whether you like it or not |
| The more...the more | Proportional | The more you read, the more you learn |
| So...that | Result | He is so tall that he can reach the ceiling |
| Such...that | Result | It was such a hot day that we stayed indoors |
| Too...to | Excess | He is too weak to walk |
| Enough...to | Sufficient | She is smart enough to solve it |
| As...as | Equal comparison | He is as tall as his brother |
| Rather...than | Preference | I would rather walk than drive |

### 3. Inversion Patterns
```
Negative adverbs at the beginning → Inversion required:

Never have I seen such beauty.
Seldom does he come here.
Rarely did she complain.
Hardly had he slept when the alarm rang.
Scarcely had she finished when the guests arrived.
No sooner did he leave than it started raining.
Not only is he smart, but also diligent.
Little did he know that he would be selected.
Only after hard work can you succeed.
Under no circumstances should you give up.
In no way can this be justified.
```

### 4. Concessive Clauses (Contrast)
```
Although/Though/Even though + Clause → Main Clause
Despite/In spite of + Noun/Gerund → Main Clause

Although he is poor, he is honest.
Despite being poor, he is honest.
In spite of his poverty, he is honest.

Complete: "Even though she studied hard, ____"
Answer: she could not pass the exam ✅

Complete: "Despite his best efforts, ____"
Answer: he failed to achieve his goal ✅
```

### 5. Purpose Clauses
```
so that / in order that / in order to / so as to

He works hard so that he can succeed.
She went early in order to get a good seat.

Complete: "He saved money ____"
Answer: so that he could buy a house ✅
```

### 6. Result Clauses
```
so + adjective + that
such + noun + that

He is so intelligent that he topped the class.
It was such a difficult question that nobody could solve it.

Complete: "The movie was so boring ____"
Answer: that the audience left halfway ✅
```

### 7. Relative Clauses
```
who/whom/which/that/whose + clause

The man who came yesterday is a doctor.
The book which I bought is interesting.
The student whose father is a doctor won the prize.

Complete: "The woman ____ lives next door is a teacher."
Answer: who ✅

Complete: "This is the house ____ was built in 1950."
Answer: that/which ✅
```

## Important Patterns for SSC CHSL

### Pattern 1: "Unless" Sentences
```
Unless = If not (NEVER use "not" with "unless")

✅ Unless you work hard, you will fail.
❌ Unless you do not work hard, you will fail.

Complete: "Unless he apologizes, ____"
Answer: I will not forgive him ✅
```

### Pattern 2: "Lest" Sentences
```
Lest = for fear that (followed by "should")

Walk carefully lest you should fall.
Study hard lest you should fail.

Complete: "He ran fast ____"
Answer: lest he should miss the train ✅
```

### Pattern 3: "Had" (Inversion in Conditionals)
```
Had I known = If I had known
Had he come = If he had come

Complete: "Had I been informed, ____"
Answer: I would have attended the meeting ✅
```

### Pattern 4: "Were" (Inversion in Conditionals)
```
Were I you = If I were you
Were he here = If he were here

Complete: "Were I the Prime Minister, ____"
Answer: I would eradicate poverty ✅
```

### Pattern 5: "As if / As though" (Unreal Comparison)
```
As if / As though + Past Tense (for present unreal)
As if / As though + Past Perfect (for past unreal)

He talks as if he knew everything. (He doesn't actually know)
She cried as though she had lost everything. (She hadn't actually lost)

Complete: "He behaves ____"
Answer: as if he were the boss ✅
```

### Pattern 6: "It is time / It is high time"
```
It is time + Past Tense (subjunctive)

It is time we left. (NOT "we leave")
It is high time you started studying.

Complete: "It is high time the government ____"
Answer: took strict action against corruption ✅
```

### Pattern 7: "Would rather / Had better"
```
Would rather + V1 (base form)
Would rather + Past Tense (for someone else)
Had better + V1

I would rather stay home.
I would rather you stayed home. (for someone else — past tense)
You had better study now.

Complete: "I would rather you ____"
Answer: didn't go there alone ✅
```

## Tips and Tricks

### ⚡ Quick-Solving Strategy
1. **Read the given part carefully** — identify the structure
2. **Identify what's missing** — subject? verb? clause? connector?
3. **Look for paired structures** — if you see "not only," look for "but also"
4. **Check tense consistency** — the completion must match the tense
5. **Check logical meaning** — the sentence must make sense overall

### 🎯 Common Exam Patterns
1. **Conditional completions** (If...then)
2. **Correlative pairs** (Not only...but also)
3. **Inversion patterns** (Hardly...when)
4. **Contrast completions** (Although...yet)
5. **Purpose/Result completions** (so that, such...that)

### 🧠 Memory Aid
```
HARNS Inversion:
H - Hardly...when
A - At no time...
R - Rarely...
N - No sooner...than / Never...
S - Scarcely...when / Seldom...
```
