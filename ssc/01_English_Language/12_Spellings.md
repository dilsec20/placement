## Introduction

Spelling questions test whether you can identify the correctly or incorrectly spelled word from given options. This is a **pure memory-based** topic — the more words you read and practice, the better you get.

**Weightage in SSC CHSL Tier 1:**
- Questions: 1-2 out of 25
- Marks: 2 marks each
- Negative marking: 0.50 marks

**Question Format:**
- "Identify the correctly spelled word" OR
- "Identify the incorrectly spelled word"

## Spelling Rules

### Rule 1: "i before e, except after c"
```
✅ believe, achieve, receive, ceiling, deceit
Exceptions: weird, seize, neither, leisure, foreign, height, science
```

### Rule 2: Dropping the Silent "e"
```
When adding a suffix that starts with a VOWEL, drop the silent "e":
make → making       hope → hoping       write → writing
love → loving       use → usable        move → movable

When adding a suffix that starts with a CONSONANT, keep the "e":
hope → hopeful      care → careful      move → movement
use → useful        love → lovely       safe → safety

Exceptions:
true → truly (drop e)      argue → argument (drop e)
judge → judgment (drop e)  acknowledge → acknowledgment (drop e)
notice → noticeable (keep e)   courage → courageous (keep e)
```

### Rule 3: Doubling the Final Consonant
```
Double the final consonant when:
1. The word ends in a single consonant
2. Preceded by a single vowel
3. The word is one syllable OR stress is on the last syllable

One syllable: run → running, sit → sitting, stop → stopping
               big → bigger, hot → hotter, thin → thinner
               plan → planned, drop → dropped

Multi-syllable (stress on last): begin → beginning, occur → occurring
                                 refer → referred, prefer → preferred
                                 admit → admitting, control → controlled

DON'T double when:
- Stress NOT on last syllable: open → opening, visit → visiting
- Ends in two consonants: jump → jumping, act → acting
- Ends in two vowels + consonant: rain → raining, read → reading
- Ends in w, x, y: play → playing, box → boxing, snow → snowing
```

### Rule 4: Words Ending in "y"
```
If consonant + y → change y to i + suffix:
happy → happiness, happily    easy → easily, easier
beauty → beautiful           carry → carried
study → studied, studies     busy → business

If vowel + y → keep y:
play → played, playing       enjoy → enjoyed, enjoying
stay → stayed                key → keys
boy → boys                   delay → delayed

Exception: say → said, pay → paid, lay → laid, day → daily
```

### Rule 5: Adding "-ly"
```
Regular: slow → slowly, quick → quickly, careful → carefully
Words ending in "le": simple → simply, possible → possibly
Words ending in "y": happy → happily, easy → easily
Words ending in "ic": basic → basically, tragic → tragically
Words ending in "ful": beautiful → beautifully, hopeful → hopefully
Words ending in "ll": full → fully, dull → dully
Exception: true → truly, whole → wholly
```

### Rule 6: Plurals
```
Regular: add "s": cat → cats, dog → dogs
Ending in s, x, z, sh, ch: add "es": bus → buses, box → boxes
Ending in consonant + y: change y to ies: city → cities, baby → babies
Ending in vowel + y: add "s": boy → boys, toy → toys
Ending in "f" or "fe": change to "ves": life → lives, knife → knives
                        Exceptions: roof → roofs, chief → chiefs, belief → beliefs
Ending in "o": 
  Add "es": potato → potatoes, tomato → tomatoes, hero → heroes
  Add "s": photo → photos, piano → pianos, radio → radios
```

### Rule 7: "-tion" vs "-sion"
```
-tion (more common): education, information, nation, creation
-sion (after "s" or "d" sounds): decision, explosion, conclusion, division
-ssion (after "ss"): mission, permission, discussion, admission
```

### Rule 8: "-able" vs "-ible"
```
-able (more common, usually with complete words):
comfortable, reasonable, valuable, readable, acceptable, dependable

-ible (usually with incomplete roots):
possible, terrible, horrible, visible, flexible, incredible, responsible

Tip: If removing the suffix leaves a complete word → "-able"
     If removing the suffix leaves an incomplete word → "-ible"
```

### Rule 9: "-ance/-ence" and "-ant/-ent"
```
-ance/-ant: importance, relevant → relevance, dominant → dominance
-ence/-ent: confidence, different → difference, excellent → excellence

No easy rule — memorize common ones:
-ance: assistance, performance, resistance, attendance, maintenance
-ence: difference, existence, experience, preference, reference
```

## Tips and Tricks

### ⚡ Quick Memory Techniques
1. **Break words into parts:** beau-ti-ful, ne-ces-sa-ry, en-vi-ron-ment
2. **Create mnemonics:**
   - **NECESSARY** = 1 Collar, 2 Sleeves (1 c, 2 s)
   - **BECAUSE** = Big Elephants Can Always Understand Small Elephants
   - **SEPARATE** = There's "A RAT" in separate
   - **CEMETERY** = All e's (no a)
   - **RHYTHM** = Rhythm Helps Your Two Hips Move
   - **ACCOMMODATION** = 2 c's, 2 m's (enough room for all)
   - **COMMITTEE** = Double m, double t, double e
3. **Say the word slowly** with correct pronunciation
4. **Write difficult words 5 times** each daily

### 🎯 Exam Strategy
1. Read each option carefully — letter by letter
2. Look for common error patterns (double letters, -ance vs -ence)
3. If unsure, go with the spelling that "looks right" (visual memory)
4. Check for silent letters — they're often missing in wrong spellings
5. Don't rush — spelling questions reward careful observation
