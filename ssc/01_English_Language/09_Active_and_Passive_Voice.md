## Introduction

Active and Passive Voice is a **high-scoring and frequently asked** topic in SSC CHSL. Questions typically ask you to convert a sentence from Active to Passive or vice versa.

**Weightage in SSC CHSL Tier 1:**
- Questions: 2-3 out of 25
- Marks: 2 marks each
- Negative marking: 0.50 marks

---

## What is Voice?

### Active Voice
The **subject performs** the action.
```
Ram (subject) writes (verb) a letter (object).
→ Focus is on the doer (Ram)
```

### Passive Voice
The **subject receives** the action.
```
A letter (subject) is written (verb) by Ram (agent).
→ Focus is on the receiver (letter)
```

### Basic Structure
```
Active:  Subject + Verb + Object
Passive: Object + Helping Verb + V3 (Past Participle) + by + Subject
```

### Pronoun Changes in Voice Conversion
| Active (Subject) | Passive (Object with "by") |
|-------------------|---------------------------|
| I | me |
| We | us |
| He | him |
| She | her |
| They | them |
| You | you |
| It | it |
| Who | whom |

## Tense-wise Conversion Rules

### Master Formula Table

| Tense | Active Voice | Passive Voice |
|-------|-------------|---------------|
| **Simple Present** | S + V1/V1s + O | O + is/am/are + V3 + by + S |
| **Present Continuous** | S + is/am/are + V1ing + O | O + is/am/are + being + V3 + by + S |
| **Present Perfect** | S + has/have + V3 + O | O + has/have + been + V3 + by + S |
| **Simple Past** | S + V2 + O | O + was/were + V3 + by + S |
| **Past Continuous** | S + was/were + V1ing + O | O + was/were + being + V3 + by + S |
| **Past Perfect** | S + had + V3 + O | O + had + been + V3 + by + S |
| **Simple Future** | S + will/shall + V1 + O | O + will/shall + be + V3 + by + S |
| **Future Perfect** | S + will/shall + have + V3 + O | O + will/shall + have + been + V3 + by + S |

> **Note:** Present Perfect Continuous, Past Perfect Continuous, Future Continuous, and Future Perfect Continuous are **NOT converted** to passive voice.

### Detailed Examples for Each Tense

### 1. Simple Present Tense
```
Formula: Object + is/am/are + V3 + by + Subject

Active:  He writes a letter.
Passive: A letter is written by him.

Active:  She teaches students.
Passive: Students are taught by her.

Active:  They play cricket.
Passive: Cricket is played by them.

Active:  I drink milk.
Passive: Milk is drunk by me.

Active:  We learn English.
Passive: English is learnt by us.
```

### 2. Present Continuous Tense
```
Formula: Object + is/am/are + being + V3 + by + Subject

Active:  He is writing a letter.
Passive: A letter is being written by him.

Active:  She is cooking food.
Passive: Food is being cooked by her.

Active:  They are playing cricket.
Passive: Cricket is being played by them.

Active:  I am reading a book.
Passive: A book is being read by me.
```

### 3. Present Perfect Tense
```
Formula: Object + has/have + been + V3 + by + Subject

Active:  He has written a letter.
Passive: A letter has been written by him.

Active:  She has completed the work.
Passive: The work has been completed by her.

Active:  They have won the match.
Passive: The match has been won by them.

Active:  I have finished the project.
Passive: The project has been finished by me.
```

### 4. Simple Past Tense
```
Formula: Object + was/were + V3 + by + Subject

Active:  He wrote a letter.
Passive: A letter was written by him.

Active:  She cooked food.
Passive: Food was cooked by her.

Active:  They played cricket.
Passive: Cricket was played by them.

Active:  Columbus discovered America.
Passive: America was discovered by Columbus.
```

### 5. Past Continuous Tense
```
Formula: Object + was/were + being + V3 + by + Subject

Active:  He was writing a letter.
Passive: A letter was being written by him.

Active:  She was cooking food.
Passive: Food was being cooked by her.

Active:  They were playing cricket.
Passive: Cricket was being played by them.
```

### 6. Past Perfect Tense
```
Formula: Object + had + been + V3 + by + Subject

Active:  He had written a letter.
Passive: A letter had been written by him.

Active:  She had finished the work.
Passive: The work had been finished by her.

Active:  They had completed the project.
Passive: The project had been completed by them.
```

### 7. Simple Future Tense
```
Formula: Object + will/shall + be + V3 + by + Subject

Active:  He will write a letter.
Passive: A letter will be written by him.

Active:  She will cook food.
Passive: Food will be cooked by her.

Active:  They will help us.
Passive: We will be helped by them.
```

### 8. Future Perfect Tense
```
Formula: Object + will/shall + have + been + V3 + by + Subject

Active:  He will have written a letter.
Passive: A letter will have been written by him.

Active:  She will have completed the task.
Passive: The task will have been completed by her.
```

## Modal Verbs in Passive Voice

### Formula: Object + Modal + be + V3 + by + Subject

| Modal | Active | Passive |
|-------|--------|---------|
| Can | He can do it. | It can be done by him. |
| Could | She could solve it. | It could be solved by her. |
| May | They may help us. | We may be helped by them. |
| Might | He might call you. | You might be called by him. |
| Must | We must follow rules. | Rules must be followed by us. |
| Should | You should respect elders. | Elders should be respected by you. |
| Would | He would help us. | We would be helped by him. |
| Ought to | She ought to help him. | He ought to be helped by her. |
| Has to | He has to do it. | It has to be done by him. |
| Had to | She had to finish it. | It had to be finished by her. |
| Used to | They used to play cricket. | Cricket used to be played by them. |
| Need to | You need to complete it. | It needs to be completed by you. |

### Modal + have + V3 (Perfect Modal)
```
Formula: Object + Modal + have + been + V3 + by + Subject

Active:  He should have done it.
Passive: It should have been done by him.

Active:  She could have solved it.
Passive: It could have been solved by her.

Active:  They must have completed the work.
Passive: The work must have been completed by them.
```

## Special Cases

### 1. Sentences with Two Objects (Direct and Indirect)
```
Active: He gave me a book.
(me = indirect object, a book = direct object)

Passive 1: I was given a book by him. (Indirect object as subject) ✅ Preferred
Passive 2: A book was given to me by him. (Direct object as subject)

Active: She taught us English.
Passive 1: We were taught English by her. ✅ Preferred
Passive 2: English was taught to us by her.

Active: Mother told me a story.
Passive 1: I was told a story by mother. ✅ Preferred
Passive 2: A story was told to me by mother.
```

### 2. Sentences with Prepositions
```
The preposition stays with the verb in passive voice.

Active:  They laughed at him.
Passive: He was laughed at by them.

Active:  People look up to him.
Passive: He is looked up to by people.

Active:  Someone broke into the house.
Passive: The house was broken into.

Active:  They spoke about the matter.
Passive: The matter was spoken about by them.
```

### 3. Sentences without Object (Intransitive Verbs)
```
Intransitive verbs CANNOT be converted to passive voice:
- He sleeps. (No object → No passive)
- She laughed. (No object → No passive)
- They went home. ("home" is not an object → No passive)

BUT some intransitive verbs used transitively CAN be:
- He runs a business. → A business is run by him. ✅
```

### 4. Quasi-Passive (Active form, Passive meaning)
```
Some sentences look active but have passive meaning:
- The book reads well. (= The book is read well)
- Honey tastes sweet. (= Honey is tasted as sweet)
- The door opened. (= The door was opened)
- Rice sells cheap. (= Rice is sold cheaply)
```

### 5. "By" Not Always Used
```
Sometimes other prepositions replace "by":

Active:  The news surprised me.
Passive: I was surprised at the news. (at, not by)

Active:  I know him.
Passive: He is known to me. (to, not by)

Active:  Her behavior pleased me.
Passive: I was pleased with her behavior. (with, not by)

Active:  The news shocked us.
Passive: We were shocked at the news. (at, not by)

Active:  This box contains books.
Passive: Books are contained in this box. (in, not by)

Active:  Grass covers the field.
Passive: The field is covered with grass. (with, not by)

Active:  His behavior annoyed me.
Passive: I was annoyed at/with his behavior.
```

## Imperative Sentences

### Formula: Let + Object + be + V3

### Commands/Orders
```
Active:  Open the door.
Passive: Let the door be opened.

Active:  Close the window.
Passive: Let the window be closed.

Active:  Do the work.
Passive: Let the work be done.

Active:  Clean the room.
Passive: Let the room be cleaned.
```

### Negative Commands
```
Active:  Do not open the door.
Passive: Let the door not be opened.

Active:  Don't make noise.
Passive: Let noise not be made. / You are ordered not to make noise.
```

### Requests (Please / Kindly)
```
Active:  Please help me.
Passive: You are requested to help me.

Active:  Kindly open the window.
Passive: You are requested to open the window.
```

### Advice
```
Active:  Work hard.
Passive: You are advised to work hard.
```

### Orders
```
Active:  Get out of here.
Passive: You are ordered to get out of here.
```

### Suggestions
```
Active:  Let us play cricket.
Passive: It is suggested that we should play cricket.
```

## Interrogative Sentences

### Yes/No Questions (Starting with Helping Verb)
```
Formula: Helping Verb + Object (as subject) + V3 + by + Subject?

Active:  Did he write a letter?
Passive: Was a letter written by him?

Active:  Has she completed the work?
Passive: Has the work been completed by her?

Active:  Will they help us?
Passive: Will we be helped by them?

Active:  Can you solve this problem?
Passive: Can this problem be solved by you?

Active:  Is he teaching the students?
Passive: Are the students being taught by him?
```

### Wh-Questions (Starting with Question Word)
```
Formula: Wh-word + Helping Verb + Object (as subject) + V3 + by + Subject?

Active:  Who wrote this book?
Passive: By whom was this book written?

Active:  What did he say?
Passive: What was said by him?

Active:  Why did they punish him?
Passive: Why was he punished by them?

Active:  When will they announce the result?
Passive: When will the result be announced by them?

Active:  Where did you find the key?
Passive: Where was the key found by you?

Special case - "Who" as subject:
Active:  Who broke the glass?
Passive: By whom was the glass broken?
```

## Tips and Tricks

### ⚡ Quick Identification Steps
1. **Identify the tense** of the active sentence
2. **Find the subject, verb, and object**
3. **Swap subject and object**
4. **Change verb form** using the formula table
5. **Add "by"** before the original subject (now agent)
6. **Change pronouns** as needed

### 🎯 Exam Shortcuts
1. **Count the helping verbs** — they tell you the tense:
   - 0 helping verbs = Simple Present/Past
   - 1 helping verb = Continuous or Perfect
   - 2 helping verbs = Perfect Continuous or Passive
   - 3 helping verbs = Perfect Continuous Passive
2. **"Being" in passive** = Continuous tense
3. **"Been" in passive** = Perfect tense
4. **"Be" in passive** = Future or Modal
5. **V3 is always present in passive voice**

### 🧠 Memory Aid: Passive Voice Pattern
```
Simple:       is/am/are/was/were + V3
Continuous:   is/am/are/was/were + being + V3
Perfect:      has/have/had + been + V3
Future:       will/shall + be + V3
Modal:        modal + be + V3
```
