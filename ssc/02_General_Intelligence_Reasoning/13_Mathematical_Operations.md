## Introduction

Mathematical Operations in Reasoning involves substituting symbols for mathematical operators (+, -, ×, ÷) and solving equations, or finding missing numbers in patterns/matrices.

**Weightage in SSC CHSL Tier 1:** 2-3 questions

## Symbol Substitution Problems

### Type 1: Replace Symbols with Operations
```
Given: + means ×, - means ÷, × means +, ÷ means -
Find: 6 + 3 - 2 × 8 ÷ 1

Replace: 6 × 3 ÷ 2 + 8 - 1
BODMAS: (6 × 3) ÷ 2 + 8 - 1 = 18 ÷ 2 + 8 - 1 = 9 + 8 - 1 = 16
Answer: 16
```

### Type 2: Replace Numbers with Numbers
```
Given: If 1 = 5, 2 = 10, 3 = 15, 4 = 20, then 5 = ?
Pattern: Each number × 5
Answer: 5 × 5 = 25
```

### Type 3: Make Equation Correct
```
Which signs should replace * to make: 3 * 4 * 2 * 1 = 11

Try: 3 × 4 - 2 + 1 = 12 - 2 + 1 = 11 ✅
Answer: ×, -, +
```

### BODMAS Rule (Always Apply!)
```
B - Brackets ()
O - Orders (powers, roots)
D - Division ÷
M - Multiplication ×
A - Addition +
S - Subtraction -

Always solve in this order after replacing symbols!
```

## Coded Inequality

### Type: Statement and Symbol Based
```
Given codes:
A @ B means A > B
A # B means A < B
A $ B means A = B
A % B means A ≥ B
A & B means A ≤ B

Question: P @ Q # R $ S
Decode: P > Q < R = S

Conclusions:
I. P > S → Can't determine (P > Q, but Q < R = S, no direct link)
II. R = S → TRUE ✅ (R $ S = R = S)
```

### Inequality Chain Rules
```
If A > B > C → A > C ✅
If A > B < C → Can't compare A and C ❌
If A < B < C → A < C ✅
If A ≥ B ≥ C → A ≥ C ✅
If A > B ≥ C → A > C ✅
If A ≥ B > C → A > C ✅

Key: Chain works ONLY if all signs point the SAME direction
```

## Missing Number Problems

### Type 1: Row/Column Pattern
```
Find the missing number (?):
| 3 | 5 | 7 |
| 2 | 4 | 6 |
| 5 | 9 | ? |

Pattern: Row 3 = Row 1 + Row 2
5 = 3+2, 9 = 5+4, ? = 7+6 = 13
Answer: 13
```

### Type 2: Diagonal Pattern
```
| 2 | 3 | 4 |
| 5 | ? | 7 |
| 8 | 9 | 10|

Check diagonals:
2 + ? + 10 = 8 + ? + 4?
Or: Each row sum = 9, 12+?, 27 → Not equal
Try: Middle = (sum of corners) / 4 = (2+4+8+10)/4 = 24/4 = 6
Answer: 6
```

### Type 3: Circle/Sector Pattern
```
A circle divided into sectors with numbers:
Usually the pattern involves:
- Opposite sectors adding to same number
- Product of adjacent sectors
- Sum of outer = center × n
```

### Type 4: Triangle Pattern
```
Numbers at vertices and center:
    4
   / \
  2   3
  (24)

Pattern: 4 × 2 × 3 = 24 ✅
Or: (4 + 2) × 3 = 18? No.

Common triangle patterns:
- Product of three vertices = center
- Sum of vertices = center
- (A × B) + C = center
- (A + B) × C = center
```

### Type 5: Box/Grid Pattern
```
Find ? in:
| 6 | 7 | 8 |
| 3 | 5 | 7 |
| 18| 35| ? |

Pattern: Row 1 × Row 2 = Row 3
6 × 3 = 18, 7 × 5 = 35, 8 × 7 = 56
Answer: 56
```

## Ranking and Order Problems

### Type 1: Linear Ranking
```
Ram is 5th from the top and 10th from the bottom.
Total students = 5 + 10 - 1 = 14

Formula: Total = Position from top + Position from bottom - 1
```

### Type 2: Interchanged Positions
```
Ram is 12th from left, Shyam is 18th from right.
After interchange: Ram is 18th from right, Shyam is 12th from left.

Total = Ram's new position from right + Shyam's position (or original positions)
We need more info OR: Total ≥ max of (12+18-1) = 29 or more
```

### Type 3: Between Two People
```
If Ram is 7th from top and Shyam is 11th from top:
People between them = |7 - 11| - 1 = 4 - 1 = 3

Formula: People between = |Position1 - Position2| - 1
```

### Type 4: Row Arrangement
```
In a row of boys facing North:
- "Right" means East
- "Left" means West
- "Right from left end" = counting from left (position from left)
- "Left from right end" = counting from right (position from right)
```

### Type 5: Position After Rearrangement
```
In alphabetical/height order rearrangement:
Ram's position changes from 5th to 8th.
This means 3 people who were behind him moved ahead (or vice versa).
```

## Statements and Conclusions / Assumptions / Arguments

### Statements and Conclusions
```
Rule: A conclusion must logically follow from the statement.
- Don't assume beyond what's stated
- Don't use general knowledge
- Only derive what can be directly concluded

Statement: "All employees must attend the training."
Conclusion I: Training is mandatory. → FOLLOWS ✅
Conclusion II: Employees don't want to attend. → DOESN'T FOLLOW ❌
```

### Statements and Assumptions
```
An assumption is something taken for granted, not explicitly stated.

Statement: "Come home early, we'll go to the market."
Assumption I: The market will be open. → IMPLICIT ✅ (assumed true)
Assumption II: You will come home. → IMPLICIT ✅ (hoped for)
```

### Statements and Arguments
```
An argument is strong if it directly relates to the statement 
and gives a valid reason for/against.

Statement: "Should the government ban plastic?"
Argument I: "Yes, plastic causes pollution." → STRONG ✅
Argument II: "No, because I like plastic bags." → WEAK ❌ (personal opinion)
```

## Tips and Tricks

### ⚡ Quick-Solving Strategy
1. **Symbol substitution:** Replace ALL symbols first, then apply BODMAS
2. **Missing numbers:** Check rows, columns, diagonals, and cross-patterns
3. **Ranking:** Always use the formula: Total = Top + Bottom - 1
4. **Inequality:** Chain works only when signs point same direction
5. **Make equation correct:** Try BODMAS-friendly combinations

### 🎯 Common Patterns in Missing Numbers
- Row sum constant
- Column sum constant
- Product pattern
- Square/cube relationship
- (A op B) op C = center
- Diagonal pattern

### 🧠 Memory Aid
```
BODMAS order: Brackets, Orders, Division, Multiplication, Addition, Subtraction
Ranking: Total = Top + Bottom - 1
Between: |Pos1 - Pos2| - 1
```
