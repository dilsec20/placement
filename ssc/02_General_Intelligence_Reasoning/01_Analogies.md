## Introduction

Analogy means **"a comparison between two things based on a similar relationship."** In SSC CHSL, you're given a pair of related words/numbers/letters, and you must find another pair with the **same type of relationship.**

**Weightage in SSC CHSL Tier 1:**
- Questions: 2-3 out of 25
- Marks: 2 marks each
- Negative marking: 0.50 marks

---

## What is an Analogy?

An analogy question presents a relationship between two items and asks you to find the same relationship in another pair.

### Format
```
A : B :: C : ?
"A is to B as C is to ?"

Example: Doctor : Hospital :: Teacher : ?
Answer: School
Relationship: Person : Workplace
```

---

## Types of Analogies

### Type 1: Word Analogies
```
Doctor : Hospital :: Teacher : School
(Person : Workplace)
```

### Type 2: Number Analogies
```
4 : 16 :: 5 : ?
Answer: 25
Relationship: n : n²
```

### Type 3: Letter Analogies
```
A : D :: B : ?
Answer: E
Relationship: +3 positions
```

### Type 4: Mixed Analogies
```
ABC : ZYX :: DEF : ?
Answer: WVU
Relationship: Reverse position (A=1→Z=26, B=2→Y=25, etc.)
```

## Step-by-Step Solving Method

### Step 1: Identify the Relationship
Ask yourself: "How is the first item related to the second?"

### Step 2: Categorize the Relationship
Is it: synonym, antonym, part-whole, person-place, tool-user, etc.?

### Step 3: Apply the Same Relationship
Apply the same relationship to the third item to find the fourth.

### Step 4: Verify
Check if the answer makes the relationship consistent.

### Example Walkthrough:
```
Pen : Writer :: Brush : ?
Step 1: Pen is used by Writer (Tool : User)
Step 2: Category = Tool : User
Step 3: Brush is used by → Painter
Step 4: Verify: Pen:Writer (tool:user) = Brush:Painter (tool:user) ✅
Answer: Painter
```

## Tips and Tricks

### ⚡ Quick Tips
1. **Always identify the relationship first** — don't guess
2. **Check both directions** — A:B or B:A
3. **For number analogies**, try: square, cube, ×2, +1, -1
4. **For letter analogies**, write position numbers: A=1, B=2...
5. **If stuck, try all options** — plug each in and check
6. **Watch for tricks** — the relationship may be less obvious

### 🎯 Common Exam Patterns
1. Synonym/Antonym pairs (most common)
2. Person : Workplace
3. Number : Square/Cube
4. Country : Capital
5. Animal : Young one
6. Product : Raw material

### 🧠 Memory Tip
Remember the alphabet position trick:
```

```
