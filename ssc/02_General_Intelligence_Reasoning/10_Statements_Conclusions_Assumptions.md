## Statements and Conclusions

### Rules
1. A conclusion MUST logically follow from the statement
2. Do NOT use personal knowledge — only what's stated
3. If a conclusion goes beyond the statement → Does NOT follow

### Common Patterns:

#### Pattern 1: Direct Conclusion
```
Statement: "All students must wear uniforms."
Conclusion: "Uniforms are mandatory for students." → FOLLOWS ✅
Conclusion: "Students like wearing uniforms." → DOES NOT FOLLOW ❌
```

#### Pattern 2: Conditional Conclusion
```
Statement: "If it rains, the match will be cancelled."
Conclusion: "It is raining." → DOES NOT FOLLOW ❌ (we don't know if it's raining)
Conclusion: "Rain can cause match cancellation." → FOLLOWS ✅
```

#### Pattern 3: Negative Conclusion
```
Statement: "No employee is allowed to leave before 5 PM."
Conclusion: "All employees must stay until 5 PM." → FOLLOWS ✅
Conclusion: "Employees are unhappy." → DOES NOT FOLLOW ❌
```

## Statements and Assumptions

### What is an Assumption?
An assumption is something **taken for granted** — not stated directly but **necessary for the statement to make sense**.

### Types:
- **Implicit:** The assumption IS hidden in the statement → Correct ✅
- **Explicit:** The assumption IS directly stated → NOT an assumption ❌
- **Unrelated:** The assumption has nothing to do with the statement → Incorrect ❌

### Common Patterns:

#### Pattern 1: Advertisement/Appeal Assumptions
```
Statement: "Use Brand X toothpaste for strong teeth."
Assumption I: "Brand X makes teeth strong." → IMPLICIT ✅ (reason for the ad)
Assumption II: "People want strong teeth." → IMPLICIT ✅ (target audience exists)
Assumption III: "All toothpastes are the same." → NOT IMPLICIT ❌
```

#### Pattern 2: Cause-Effect Assumptions
```
Statement: "The government increased taxes to reduce the fiscal deficit."
Assumption: "Increased taxes will reduce the fiscal deficit." → IMPLICIT ✅
Assumption: "People will pay more taxes willingly." → NOT IMPLICIT ❌ (not required for statement)
```

#### Pattern 3: Advice/Instruction Assumptions
```
Statement: "Take an umbrella, it might rain."
Assumption: "An umbrella protects from rain." → IMPLICIT ✅
Assumption: "It will definitely rain." → NOT IMPLICIT ❌ ("might" ≠ "will")
```

### Test for Assumption:
> "Would the statement make sense if this assumption were FALSE?"
> If removing the assumption makes the statement meaningless → IMPLICIT

## Statements and Arguments

### Strong Argument:
- Directly related to the topic
- Gives a valid, logical reason
- Based on facts, not emotions or vague claims
- Significant enough to matter

### Weak Argument:
- Based on personal opinion
- Too vague or general
- Emotional appeal without logic
- Irrelevant to the topic

### Examples:
```
Statement: "Should plastic bags be banned?"

Strong: "Yes, plastic bags pollute the environment severely." ✅ (factual, relevant)
Strong: "No, banning plastic suddenly will affect many businesses." ✅ (practical concern)
Weak: "Yes, because I don't like plastic." ❌ (personal opinion)
Weak: "No, because everyone uses them." ❌ (not a valid reason to continue)
```

## Cause and Effect

### Rules:
```
Identify which event is the CAUSE and which is the EFFECT:
- The cause HAPPENS FIRST
- The effect is the RESULT of the cause
- Both should be logically connected

Statement I: "Heavy rains lashed the city."
Statement II: "Many areas were waterlogged."
Answer: Statement I is the CAUSE, Statement II is the EFFECT ✅

Statement I: "Schools were closed."
Statement II: "A major storm warning was issued."
Answer: Statement II is the CAUSE, Statement I is the EFFECT ✅
```

## Tips and Tricks

### ⚡ Quick Decision Framework:
1. **Conclusions:** Does it LOGICALLY follow? (No assumptions, no extra info)
2. **Assumptions:** Is it NECESSARY for the statement? (Hidden but required)
3. **Arguments:** Is it RELEVANT and LOGICAL? (Not emotional or vague)
4. **Cause-Effect:** Which happened FIRST and CAUSED the other?

### 🎯 Red Flags (Usually Wrong):
- "All" or "None" in conclusions (usually too extreme)
- Personal opinions in arguments
- Assumptions that are explicitly stated
- Conclusions that add new information
