## Embedded Figures

### What are Embedded Figures?
A small figure (question figure) is hidden inside a larger, complex figure. You must identify WHICH option contains the question figure embedded within it.

### Rules:
```
1. The embedded figure must be EXACTLY the same shape and size
2. It can be ROTATED but NOT mirrored or distorted
3. It must be a PART of the larger figure
4. The lines of the embedded figure must coincide with lines of the larger figure
```

### Solving Strategy:
```
Step 1: Study the question figure carefully — note its key features
Step 2: Look at each option and try to "find" the question figure within it
Step 3: Trace the question figure's outline within the complex figure
Step 4: The lines must match exactly
Step 5: Eliminate options where the figure doesn't fit
```

### Common Shapes That Get Embedded:
- Triangles inside complex star patterns
- Squares/rectangles inside grid patterns
- Circles inside overlapping circle designs
- L-shapes inside maze-like patterns
- Pentagons inside complex geometric figures

### Tips for Embedded Figures:
```
1. Start with the most DISTINCTIVE feature of the question figure
2. Look for that feature in each option
3. If a figure has a right angle — look for right angles
4. If it has a curved side — look for curves
5. Count the sides/vertices to narrow down options
```

## Figure Completion

### Concept:
A figure is partially shown, and you must find which option completes it to form a meaningful or symmetrical pattern.

### Types:
```
Type 1: Complete the square/rectangle
- A portion of a 2×2 grid is given
- Find the missing quarter

Type 2: Complete the pattern
- A symmetrical figure with a missing section
- Choose the option that completes it symmetrically

Type 3: Figure series completion
- A series of figures with a pattern
- Find the next figure
```

## Data Sufficiency

### Concept:
You're given a question and two statements. Determine whether the statements provide enough information to answer the question.

### Answer Options (Standard):
```
(a) Statement I alone is sufficient
(b) Statement II alone is sufficient
(c) Both statements together are sufficient
(d) Neither statement is sufficient
(e) Each statement alone is sufficient
```

### Solving Method:
```
Step 1: Read the question carefully
Step 2: Try to answer using ONLY Statement I
  - If YES → answer is (a) or (e) (check Statement II too)
  - If NO → proceed to Step 3
Step 3: Try to answer using ONLY Statement II
  - If YES → answer is (b) or (e)
  - If NO → proceed to Step 4
Step 4: Try combining both statements
  - If YES → answer is (c)
  - If NO → answer is (d)
```

### Example:
```
Question: What is the age of Ram?

Statement I: Ram is 5 years older than Shyam.
Statement II: Shyam is 20 years old.

Analysis:
- Statement I alone: Ram = Shyam + 5, but we don't know Shyam's age → NOT sufficient
- Statement II alone: Shyam = 20, but no link to Ram → NOT sufficient
- Both together: Shyam = 20, Ram = 20 + 5 = 25 → SUFFICIENT

Answer: (c) Both statements together are sufficient ✅
```

## Logical Puzzles (Seating Arrangement)

### Linear Arrangement
```
People sitting in a row (facing same direction):
- "Right of" = towards right when facing same direction
- "Left of" = towards left

Facing North: Left is West, Right is East
Facing South: Left is East, Right is West

Example:
A sits 3rd from the left end.
B sits 2nd to the right of A.
B's position from left = 3 + 2 = 5th from left

Positions: _ _ A _ B _ _
```

### Circular Arrangement
```
People sitting around a round table:
- "Immediate right" = next person clockwise
- "Immediate left" = next person anti-clockwise

When facing CENTER:
- Right = Clockwise
- Left = Anti-clockwise

When facing OUTWARD:
- Right = Anti-clockwise
- Left = Clockwise

Example:
6 people A, B, C, D, E, F sitting around a table facing center.
A sits opposite D.
B sits to the right of A.
C sits opposite B.

     F
   /    \
  E      A
  |      |
  D      B
   \    /
     C
```

### Floor Arrangement
```
People on different floors:
- "Above" = higher floor number
- "Below" = lower floor number

Example: 5-floor building
Floor 5 (top): ?
Floor 4: ?
Floor 3: A
Floor 2: ?
Floor 1 (bottom): ?

"B lives 2 floors above A" → B is on Floor 5
"C lives just below B" → C is on Floor 4
```

### Solving Strategy for Puzzles:
```
1. Read ALL clues first before drawing
2. Start with the most definite information
3. Use tables/grids to organize information
4. Fill in what you KNOW, then derive the rest
5. Use elimination for remaining positions
6. Verify your answer against ALL given clues
```

## Tips and Tricks

### ⚡ Quick-Solving Strategy:
1. **Embedded figures:** Look for the most unique feature first
2. **Data sufficiency:** Try each statement separately, then together
3. **Puzzles:** Draw diagrams — tables for linear, circles for round table
4. **Figure completion:** Look for symmetry lines

### 🎯 Common Traps:
1. **Embedded:** Rotated figure is valid; mirrored is NOT
2. **Data sufficiency:** Don't solve the problem — just check IF it CAN be solved
3. **Puzzles:** "Right" means different things based on facing direction
4. **Circular:** Facing center vs facing outward changes left/right
