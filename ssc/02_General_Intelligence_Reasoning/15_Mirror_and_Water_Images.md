## Introduction

Mirror and Water Image questions test your ability to visualize how objects appear when reflected. Mirror images flip horizontally (left-right), while water images flip vertically (up-down).

**Weightage in SSC CHSL Tier 1:** 1-2 questions

---

## Mirror Images

### Concept
```
A mirror placed to the RIGHT of an object:
- Left and Right are REVERSED
- Top and Bottom remain SAME
- The image is a LATERAL INVERSION

Think of standing in front of a mirror:
- Your left hand appears as right hand in the mirror
- Your head stays on top, feet stay at bottom
```

### Rule for Mirror Images
```
When mirror is on the RIGHT side:
- Everything flips LEFT ↔ RIGHT
- Direction of text reverses
- Top/Bottom unchanged

When mirror is on the LEFT side:
- Same as above (left-right flip)

When mirror is on TOP:
- Top and Bottom flip (like water image!)
- Left/Right unchanged

When mirror is on BOTTOM:
- Same as top mirror (up-down flip)
```

## Mirror Images of Letters

### Letters That Look SAME in Mirror
```
Vertically symmetrical letters (same in mirror placed on right):
A, H, I, M, O, T, U, V, W, X, Y

These letters look identical in a mirror.
```

### Letters That CHANGE in Mirror
```
B → ᗺ (reversed B)
C → Ↄ (reversed C)
D → ᗡ (reversed D)
E → Ǝ (reversed E)
F → ꟻ (reversed F)
G → Ꭾ (reversed G)
J → Ꞁ (reversed J)
K → ꓘ (reversed K)
L → ⅃ (reversed L)
N → Ͷ (reversed N)
P → ꟼ (reversed P)
Q → Ọ (reversed Q)
R → Я (reversed R)
S → Ꙅ (reversed S)
Z → Ƹ (reversed Z)
```

### Letters Symmetric in BOTH Axes (Same in Mirror AND Water Image)
```
H, I, O, X
These letters look the same no matter how you reflect them.
```

### Mirror Image of Words
```
The word reverses completely:

HELLO → OᒧᒧƎH (each letter reversed AND order reversed)
APPLE → ƎᒧꟼꟼA

For the exam, simply:
1. Reverse the order of letters
2. Each letter becomes its mirror image

Example: 
CAT → TAƆ (read right to left in mirror)
```

### Mirror Image of Numbers
```
Numbers that look SAME: 0, 8 (vertically symmetric)
Numbers that look SAME (approximately): 1 (depends on font)

Numbers that CHANGE:
2 → Ƹ    3 → Ɛ    4 → Ƛ    5 → Ƨ    6 → ꓐ    7 → Ɣ    9 → Ꝯ

Number sequence reverses:
1234 → mirror shows → 4321 (reversed, each digit mirrored)
```

## Water Images

### Concept
```
A water image is the reflection you see when looking at an object 
reflected in water (like a lake or pool).

- Top and Bottom are REVERSED
- Left and Right remain SAME
- The image is an UPSIDE-DOWN version

Think of a tree reflected in a lake:
- The top of the tree appears at the bottom
- The trunk (bottom) appears at the top
- Left side stays on left, right stays on right
```

### Water Image Rule
```
Flip the object UPSIDE DOWN:
- Top becomes Bottom
- Bottom becomes Top
- Left stays Left
- Right stays Right
```

### Letters That Look SAME in Water Image
```
Horizontally symmetrical letters:
B, C, D, E, H, I, K, O, X

These letters look the same when flipped upside down.
```

### Letters That CHANGE in Water Image
```
A → ∀ (upside down A)
F → Ⅎ
G → ⅁
J → ſ
L → Γ
M → W (M becomes W, W becomes M!)
N → ᴎ
P → b (P becomes like b)
Q → Ò
R → ᴚ
S → Ƨ (S flipped vertically)
T → ⊥
U → ∩ (U becomes ∩, horseshoe)
V → ∧
W → M
Y → ʎ
Z → Z (approximately same)
```

## Mirror Image vs Water Image — Comparison

| Feature | Mirror Image | Water Image |
|---------|-------------|-------------|
| Flip direction | Left ↔ Right | Top ↔ Bottom |
| Text | Reversed horizontally | Flipped vertically |
| Clock | Subtract from 11:60 | Subtract from 5:60/17:60 |
| Same letters | A,H,I,M,O,T,U,V,W,X,Y | B,C,D,E,H,I,K,O,X |
| Both same | H, I, O, X | H, I, O, X |

## Mirror/Water Images of Clocks

### Mirror Image of Clock
```
Formula: 11:60 - Actual Time (or 12:00 for exact hours)

Example: Clock shows 3:15
Mirror image = 11:60 - 3:15 = 8:45

Example: Clock shows 7:40
Mirror image = 11:60 - 7:40 = 4:20
```

### Water Image of Clock
```
Formula: 18:30 - Actual Time (or simpler: 17:60 - Actual Time, then mod 12)

Simpler method: Subtract from 12:30 (if result is negative, add 12)

Example: Clock shows 3:15
Water image = 12:30 - 3:15 = 9:15

Example: Clock shows 9:45
Water image = 12:30 - 9:45 → 11:90 - 9:45 = 2:45? 
Let's use: 18:30 - 9:45 = 8:45 → This is in 12-hr: 8:45

Actually, the most reliable water image formula is:
Water = 18:30 - Time (take mod 12 if needed)
OR
Just flip top-bottom of the clock face visually
```

## Figure-Based Mirror/Water Images

### Rules for Figures
```
Mirror Image (vertical mirror on right):
1. The figure flips left-to-right
2. If an arrow points left → it points right in mirror
3. If a shape is on the left side → it appears on the right side
4. Angles and proportions remain the same

Water Image (horizontal reflection below):
1. The figure flips top-to-bottom
2. If an arrow points up → it points down
3. The top part goes to the bottom
4. Left-right positions don't change
```

### How to Solve Figure Questions
```
Step 1: Identify the mirror/water line
Step 2: For mirror → flip left-right
        For water → flip top-bottom
Step 3: Check each detail in the original vs options
Step 4: Eliminate wrong options one by one
```

## Tips and Tricks

### ⚡ Quick-Solving Strategy
1. **For letters/words:** Memorize which letters stay same
2. **For clocks:** Use the subtraction formulas
3. **For figures:** Mentally flip along the correct axis
4. **Mirror = left-right flip; Water = top-bottom flip**

### 🎯 Common Traps
1. Confusing mirror with water image
2. Not flipping individual characters in text
3. For figures, forgetting to maintain proportions
4. Clock image calculations — check if > 12:00

### 🧠 Memory Aids
```
Mirror Image = "Looking at yourself in a mirror" → L and R swap
Water Image = "Looking at reflection in a lake" → U and D swap

Same in Mirror: "A HIT MoVe WaXY" → A, H, I, T, M, O, V, W, X, Y
Same in Water: "BeCDEHIKOX" → B, C, D, E, H, I, K, O, X
Same in BOTH: "HIOX" → H, I, O, X
```
