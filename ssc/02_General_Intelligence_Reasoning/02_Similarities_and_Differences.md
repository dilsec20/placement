## Introduction

Similarities and Differences (also called **Classification**) test your ability to identify common traits among items and spot the odd one that doesn't belong. You're given 4-5 items and must find which one is different from the rest, or which group shares a common property.

**Weightage in SSC CHSL Tier 1:** 2-3 questions

---

## Types of Questions

### Type 1: Word Classification
> Find the odd one out: Apple, Mango, Potato, Banana
> Answer: **Potato** (others are fruits; potato is a vegetable)

### Type 2: Number Classification
> Find the odd one out: 2, 3, 5, 9, 11
> Answer: **9** (others are prime numbers; 9 = 3×3)

### Type 3: Letter Classification
> Find the odd one out: AE, BF, CG, DI
> Answer: **DI** (others have gap of 4; DI has gap of 5)

### Type 4: Figure Classification
> Visual figures grouped by shape, rotation, shading, etc.

## Classification Concepts

### How to Find Similarity
1. **Identify the common property** shared by most items
2. **The odd one** lacks this property
3. Common properties: category, number pattern, letter pattern, position

### Key Properties to Check

#### For Words:
- Same category (fruits, animals, countries, etc.)
- Same first/last letter
- Same number of letters
- Same gender (masculine/feminine)
- Same part of speech

#### For Numbers:
- All prime / All composite
- All even / All odd
- All squares / All cubes
- Same pattern (n²+1, n²-1, etc.)
- Divisibility by same number

#### For Letters:
- Same position gap
- All vowels / All consonants
- Same pattern (forward/backward skip)
- Symmetrical letters

## Tips and Tricks

### ⚡ Quick-Solving Strategy
1. **Look at all items first** — what do most have in common?
2. **Find the common thread** — category, pattern, property
3. **Identify the outlier** — which one doesn't fit?
4. **Verify** — make sure the odd one is truly different

### 🎯 Common Traps
1. **Subtle differences** — Bat is a mammal (not a bird)
2. **Whale is a mammal** (not a fish)
3. **Tomato is botanically a fruit** (but culinarily a vegetable)
4. **Spider has 8 legs** (not an insect — insects have 6)
5. **Mushroom is a fungus** (not a plant)

### 🧠 Number Classification Tips
- Check if all are **prime** (2, 3, 5, 7, 11, 13...)
- Check if all are **squares** (1, 4, 9, 16, 25...)
- Check if all are **cubes** (1, 8, 27, 64, 125...)
- Check **divisibility** patterns
- Check for **n² + 1**, **n² - 1**, **n(n+1)** patterns
