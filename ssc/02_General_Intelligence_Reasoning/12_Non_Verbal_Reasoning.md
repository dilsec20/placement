## Introduction

Non-Verbal Reasoning uses figures/images instead of words or numbers. You must identify patterns in shapes, rotations, reflections, and transformations.

**Weightage in SSC CHSL Tier 1:** 3-5 questions (total across all figure types)

---

## Figure Series

### Common Transformations:
```
1. ROTATION: Figure rotates clockwise/anti-clockwise by fixed degrees
   - 45°, 90°, 180° are most common

2. ADDITION: Elements are added in each step
   - One more line, one more dot, one more shape

3. REMOVAL: Elements are removed in each step

4. SHADING CHANGE: 
   - White → Half-shaded → Full-shaded → White (cycle)
   - Shading moves position

5. SIZE CHANGE: Shape grows/shrinks in each step

6. POSITION CHANGE: Element moves to different position
   - Clockwise movement around a grid
   - Diagonal movement

7. SHAPE CHANGE: Shape changes in a sequence
   - Circle → Triangle → Square → Pentagon (sides increase)

8. COUNT CHANGE: Number of elements changes
   - 1, 2, 3, 4, ? (increasing by 1)
   - 1, 2, 4, 8, ? (doubling)
```

### Solving Strategy:
```
Step 1: Look at the OVERALL pattern first
Step 2: Check each ELEMENT separately
Step 3: Track CHANGES from figure to figure:
  - Does anything rotate?
  - Does anything move?
  - Does anything appear/disappear?
  - Does shading change?
Step 4: Apply the pattern to find the answer
```

## Figure Analogy

### Concept:
```
Figure A : Figure B :: Figure C : ?

The relationship between A and B must be the same as between C and the answer.

Common relationships:
- A is rotated 90° = B → C rotated 90° = answer
- A gains an element = B → C gains same element = answer
- A is mirror of B → C's mirror = answer
- A's shading inverts = B → C's shading inverts = answer
```

## Figure Classification

### Concept:
```
5 figures given. 4 share a common property. Find the odd one.

Check for:
- Number of lines/curves
- Number of enclosed regions
- Symmetry (symmetric vs asymmetric)
- Open vs closed figures
- Straight vs curved lines
- Number of dots/elements
- Direction of arrows/pointers
```

---

## Pattern Completion (Matrix)

### Concept:
```
A 3×3 matrix with the bottom-right cell missing.
Find the pattern across rows and columns.

Common patterns:
- Each row has the same elements in different arrangements
- Each column follows a transformation
- Diagonal patterns
- Rotation pattern across the matrix
```

## Figure Counting

### Counting Triangles
```
Basic formulas for common figures:

Triangle divided by lines from one vertex:
With n lines from vertex → n(n+1)/2 triangles... (varies)

Equilateral triangle with internal divisions:
Upward triangles + Downward triangles

Specific cases:
- Triangle with 1 line from vertex to opposite side: 3 triangles
- Triangle with 2 lines from vertex: 6 triangles
- Triangle within a triangle: Count smallest, then combinations
```

### Counting Squares
```
In an n×n grid:
Total squares = n² + (n-1)² + (n-2)² + ... + 1²
= n(n+1)(2n+1)/6

Examples:
1×1 grid: 1 square
2×2 grid: 4 + 1 = 5 squares
3×3 grid: 9 + 4 + 1 = 14 squares
4×4 grid: 16 + 9 + 4 + 1 = 30 squares
5×5 grid: 25 + 16 + 9 + 4 + 1 = 55 squares
```

### Counting Rectangles (including squares)
```
In an m×n grid:
Total rectangles = [m(m+1)/2] × [n(n+1)/2]

For square grid (n×n):
Total rectangles = [n(n+1)/2]²

Examples:
2×2 grid: (2×3/2)² = 3² = 9 rectangles
3×3 grid: (3×4/2)² = 6² = 36 rectangles
4×4 grid: (4×5/2)² = 10² = 100 rectangles
```

### Counting Straight Lines
```
In a figure, count each distinct line segment:
- Count the smallest segments first
- Then count combinations of 2 consecutive segments
- Then combinations of 3, and so on
```

## Tips and Tricks

### ⚡ Quick-Solving Strategy:
1. **Figure Series:** Track each element's change separately
2. **Figure Analogy:** Identify the A→B transformation, apply to C
3. **Classification:** Look for the most obvious common property
4. **Counting:** Start with smallest shapes, then build up
5. **Pattern completion:** Check both rows AND columns

### 🎯 Common Elements to Track:
```
- Rotation direction and angle
- Number of sides/vertices
- Shading (filled, empty, half)
- Size (small, medium, large)
- Position (corner, center, edge)
- Orientation (up, down, left, right)
- Arrows/lines direction
- Open vs closed shapes
```

### 🧠 Counting Formulas:
```
Squares in n×n grid = n(n+1)(2n+1)/6
Rectangles in m×n grid = m(m+1)×n(n+1)/4
Triangles = Count systematically (no universal formula)
```

## PYQ Patterns

Most figure-based questions in SSC CHSL follow these patterns:
1. **Figure series** (2-3 questions): Find the next figure
2. **Figure analogy** (1 question): A:B::C:?
3. **Embedded/Classification** (1-2 questions): Find the odd figure
4. **Counting** (1 question): Count triangles/squares/rectangles

All are visual — practice with previous year papers and mock tests for the best preparation!

> **Final Tip:** Non-verbal reasoning is a VISUAL skill. Practice by solving at least 10 figure-based questions daily. Look for patterns in rotation, addition/deletion, and shading changes! 🔄
