## Ratio and Proportion

### Basic Concepts
```
Ratio: Comparison of two quantities → a:b = a/b
Proportion: Equality of two ratios → a:b = c:d → a/b = c/d

Terms:
a:b → a is antecedent, b is consequent
a:b::c:d → a,d are extremes; b,c are means
Product of extremes = Product of means → ad = bc
```

### Properties of Ratios
```
1. a:b = ka:kb (multiply/divide both by same number)
2. a:b = c:d → a/c = b/d (alternendo)
3. a:b = c:d → a/b = c/d (same ratio)
4. a:b = c:d → (a+b)/b = (c+d)/d (componendo)
5. a:b = c:d → (a-b)/b = (c-d)/d (dividendo)
6. a:b = c:d → (a+b)/(a-b) = (c+d)/(c-d) (componendo-dividendo)
```

### Types of Proportion
```
Direct Proportion: If A increases, B increases at same rate
  A/B = constant → A₁/B₁ = A₂/B₂

Inverse Proportion: If A increases, B decreases
  A×B = constant → A₁×B₁ = A₂×B₂

Continued Proportion: a:b = b:c → b² = ac
  b is called the Mean Proportional of a and c
  b = √(ac)

Third Proportional: If a:b = b:c → c = b²/a
```

### Key Formulas
```
If A:B = 2:3 and B:C = 4:5
To find A:B:C → Make B common
A:B = 2:3 = 8:12 (multiply by 4)
B:C = 4:5 = 12:15 (multiply by 3)
A:B:C = 8:12:15

Dividing in a Ratio:
If amount P is divided in ratio a:b:c:
First share = P × a/(a+b+c)
Second share = P × b/(a+b+c)
Third share = P × c/(a+b+c)

Example: ₹600 divided in 2:3:5
First = 600 × 2/10 = 120
Second = 600 × 3/10 = 180
Third = 600 × 5/10 = 300
```

## Average

### Basic Formula
```
Average = Sum of all values / Number of values
Sum = Average × Number of values
```

### Important Average Formulas
```
Average of first n natural numbers = (n+1)/2
Average of first n even numbers = (n+1)
Average of first n odd numbers = n
Average of consecutive numbers from a to b = (a+b)/2
```

### Weighted Average
```
If n₁ items have average a₁ and n₂ items have average a₂:
Combined average = (n₁×a₁ + n₂×a₂)/(n₁+n₂)

Example: 20 students avg 60, 30 students avg 70:
Combined = (20×60 + 30×70)/50 = (1200+2100)/50 = 66
```

### Adding/Removing a Person
```
When a new person joins:
New member's value = New Average + n × (New Average - Old Average)
where n = new total number

When a person leaves:
Removed person's value = Old Average - n × (New Average - Old Average)
where n = new total number
```

### Age Problems with Average
```
Average age of family = Sum of ages / Number of members

After t years: New average = Old average + t
(Everyone ages by t years)

When a new member joins/born:
Calculate using sum before and after
```

## Mixture and Alligation

### Basic Mixture
```
If two quantities of cost c₁ and c₂ are mixed:
Mean price = (c₁×q₁ + c₂×q₂)/(q₁+q₂)
```

### Alligation Rule
```
When two ingredients of price c₁ and c₂ are mixed to get mix of price cm:

Ratio = q₁/q₂ = (c₂ - cm)/(cm - c₁)

"Cheaper quantity / Dearer quantity = (Dearer price - Mean) / (Mean - Cheaper)"

Diagram:
    c₁ (cheaper)        c₂ (dearer)
         \                  /
          \                /
           cm (mean/mix price)
          /                \
         /                  \
    (c₂-cm)              (cm-c₁)
    
Ratio = (c₂-cm) : (cm-c₁)
```

### Replacement Formula
```
If a vessel contains 'a' litres of liquid A.
Each time 'b' litres are taken out and replaced with liquid B.
After n operations:

Quantity of A left = a × (1 - b/a)ⁿ

Example: 20L milk, 4L replaced with water each time. After 3 times:
Milk left = 20 × (1 - 4/20)³ = 20 × (4/5)³ = 20 × 64/125 = 10.24L
```

## Tips and Tricks

### ⚡ Quick Shortcuts
```
1. Ratio joining: Make common term equal, then combine
2. Average of AP (arithmetic progression): Average = middle term
3. For consecutive numbers: Average = (first + last)/2
4. Alligation cross method: Always put cheaper on left

Quick averages:
First 10 natural numbers: (10+1)/2 = 5.5
First 10 even: 10+1 = 11
First 10 odd: 10
Numbers 1 to 100: (1+100)/2 = 50.5
```

### PYQ 2 — SSC CHSL 2023
**Q.** Average of 5 numbers is 20. One number removed, average becomes 15. Removed number?
- Sum = 5×20 = 100; New sum = 4×15 = 60; Removed = 100-60 = 40
- Answer: **40** ✅

### PYQ 3 — SSC CHSL 2022
**Q.** Mix 20L of ₹40/L with 30L of ₹60/L. Average price?
- (20×40+30×60)/50 = (800+1800)/50 = 52
- Answer: **₹52/L** ✅

- A:B:C → A:B=15:20, B:C=20:24 → A:B:C=15:20:24 → A:C=15:24=5:8
- Answer: **5:8** ✅
