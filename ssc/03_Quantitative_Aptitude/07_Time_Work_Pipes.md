## Basic Concept

```
If a person can do a work in 'n' days:
Work done in 1 day = 1/n (this is the EFFICIENCY)

If A does work in 20 days → A's 1-day work = 1/20
If B does work in 30 days → B's 1-day work = 1/30

Together: 1/20 + 1/30 = 3/60 + 2/60 = 5/60 = 1/12
They finish in 12 days together.
```

## All Formulas

### Basic Formulas
```
1. If A can do in a days, B in b days:
   Together = ab/(a+b) days

2. If A and B together finish in T days, A alone in a days:
   B alone = aT/(a-T) days

3. If A is x times as efficient as B:
   Time ratio = 1:x (A takes 1/x the time of B)
   Efficiency ratio = x:1

4. Work = Efficiency × Time
   W = E × T

5. MDH formula (Men × Days × Hours = constant for same work):
   M₁ × D₁ × H₁ = M₂ × D₂ × H₂
   
   Extended: M₁×D₁×H₁/W₁ = M₂×D₂×H₂/W₂
```

### LCM Method (Best Method for SSC!)
```
Step 1: Find LCM of days taken by each person
Step 2: This LCM = Total work units
Step 3: Each person's efficiency = Total work / Their days
Step 4: Combined efficiency = Sum of efficiencies
Step 5: Time together = Total work / Combined efficiency

Example: A=20 days, B=30 days
LCM(20,30) = 60 units = Total work
A's efficiency = 60/20 = 3 units/day
B's efficiency = 60/30 = 2 units/day
Together = 60/(3+2) = 60/5 = 12 days ✅
```

## Work and Efficiency

### Alternate Working Days
```
If A and B work on alternate days:
Calculate work done in 2-day cycle.

Example: A=12 days, B=18 days. Work alternately starting with A.
LCM(12,18) = 36 units
A = 3 units/day, B = 2 units/day
2-day cycle: 3+2 = 5 units
Cycles needed: 36/5 = 7 cycles + 1 unit remaining
= 7×2 = 14 days + A works day 15 (does 3 units, only 1 needed)
= 14 + 1/3 day
Answer: 14⅓ days
```

### A Works for Some Days, Then B Joins
```
Example: A alone in 20 days. After 5 days, B joins. Together finish in 4 more days.
A's 1-day = 1/20
In 5 days, A does = 5/20 = 1/4
Remaining = 3/4
(A+B) finish 3/4 in 4 days → (A+B) per day = 3/16
B per day = 3/16 - 1/20 = (15-4)/80 = 11/80
B alone = 80/11 days ≈ 7.27 days
```

### Work Done by a Group
```
If 5 men can do work in 10 days, how many days for 8 men?
M₁D₁ = M₂D₂
5 × 10 = 8 × D₂
D₂ = 50/8 = 6.25 days
```

### Men, Women, Children
```
If 2 men = 3 women = 5 children (in terms of efficiency)
Let 1 man = m, 1 woman = w, 1 child = c
2m = 3w → w = 2m/3
2m = 5c → c = 2m/5

Example: 2 men finish in 10 days. How long for 3 women?
Work = 2m × 10 = 20m
3 women = 3 × 2m/3 = 2m
Time = 20m/2m = 10 days
```

## Pipes and Cisterns

### Basic Concept
```
Filling pipe = positive work (like a worker doing work)
Emptying/outlet pipe = negative work (like destroying work)

If pipe A fills in a hours → Rate = 1/a (positive)
If pipe B empties in b hours → Rate = 1/b (negative)
Together → Rate = 1/a - 1/b
```

### All Pipe Formulas
```
1. Two filling pipes (a and b hours):
   Together = ab/(a+b) hours

2. One filling (a hours), one emptying (b hours):
   Together = ab/(b-a) hours [if b > a, tank fills]
   Together = ab/(a-b) hours [if a > b, tank empties]

3. Net rate = Sum of filling rates - Sum of emptying rates

4. Tank capacity = LCM of all pipe times
```

### LCM Method for Pipes
```
Pipe A fills in 6 hours, B fills in 8 hours, C empties in 12 hours.
LCM(6,8,12) = 24 units (tank capacity)

A's rate = 24/6 = +4 units/hour (filling)
B's rate = 24/8 = +3 units/hour (filling)
C's rate = 24/12 = -2 units/hour (emptying)

All together: 4 + 3 - 2 = 5 units/hour
Time = 24/5 = 4.8 hours = 4 hours 48 minutes
```

### Leak Problems
```
Without leak: fills in a hours → rate = 1/a
With leak: fills in b hours → rate = 1/b
Leak rate = 1/a - 1/b = (b-a)/ab
Leak empties full tank in = ab/(b-a) hours
```

## Tips and Tricks

### ⚡ Quick Shortcuts
```
1. LCM method is FASTEST — always use it
2. If A is twice as efficient as B and together they take T days:
   A alone = 3T/2, B alone = 3T
3. Work = Rate × Time (like Distance = Speed × Time)
4. For pipes: Filling = positive, Emptying = negative
5. MDH: More men → fewer days; More hours → fewer days

Quick two-person formula:
Together = (a×b)/(a+b) days — MEMORIZE THIS!
```

### 🎯 Key Conversions
```
Fraction to completion time:
1/2 work done → half the time
1/3 work done → one-third the time

If total work = 1, and rate = 1/n per day:
Days to complete = n
Days for half work = n/2
```

## Last 10 Years PYQs

### PYQ 1 — SSC CHSL 2024
**Q.** A can do in 12 days, B in 18 days. Together how long?
- ab/(a+b) = 12×18/30 = 216/30 = 7.2 days
- Answer: **7.2 days** ✅

### PYQ 2 — SSC CHSL 2023
**Q.** 10 men can do work in 15 days. 12 men how many days?
- M₁D₁=M₂D₂ → 10×15=12×D → D=150/12=12.5
- Answer: **12.5 days** ✅

### PYQ 3 — SSC CHSL 2022
**Q.** Pipe A fills in 10 hours, B empties in 15 hours. Together?
- ab/(b-a) = 10×15/(15-10) = 150/5 = 30 hours to fill
- Answer: **30 hours** ✅

### PYQ 4 — SSC CHSL 2021
**Q.** A and B together in 8 days. A alone in 12 days. B alone?
- B = aT/(a-T) = 12×8/(12-8) = 96/4 = 24 days
- Answer: **24 days** ✅

### PYQ 5 — SSC CHSL 2020
**Q.** A is twice as fast as B. Together finish in 6 days. A alone?
- Let B's rate=1, A's rate=2. Together=3 rates.
- 3 rates × 6 days = 18 units. A alone = 18/2 = 9 days
- Answer: **9 days** ✅

---

> **Final Tip:** ALWAYS use the LCM method — it converts fractions to whole numbers and makes calculation much easier. For pipes, filling = positive, emptying = negative. Together formula = ab/(a+b)! ⏱️
