## Simplification (BODMAS)

### Order of Operations
```
B → Brackets: (), {}, []
O → Orders: Powers, Roots
D → Division: ÷
M → Multiplication: ×
A → Addition: +
S → Subtraction: -

Within brackets: Solve in order: (), {}, []
Same level operations: Left to right
```

### Surds and Indices
```
aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
a⁰ = 1
a⁻ⁿ = 1/aⁿ
a^(1/n) = ⁿ√a

√a × √b = √(ab)
√a / √b = √(a/b)
(√a)² = a
```

### Approximation Tricks
```
For quick calculations:
√2 ≈ 1.414    √3 ≈ 1.732    √5 ≈ 2.236
√6 ≈ 2.449    √7 ≈ 2.646    √10 ≈ 3.162

Fractions to decimals:
1/3 = 0.333    1/6 = 0.167    1/7 = 0.143
1/8 = 0.125    1/9 = 0.111    1/11 = 0.0909
1/12 = 0.083   1/13 = 0.077   1/15 = 0.067
```

## Algebra

### Key Identities (MUST MEMORIZE)
```
(a+b)² = a²+2ab+b²
(a-b)² = a²-2ab+b²
a²-b² = (a+b)(a-b)

(a+b)³ = a³+3a²b+3ab²+b³ = a³+b³+3ab(a+b)
(a-b)³ = a³-3a²b+3ab²-b³ = a³-b³-3ab(a-b)

a³+b³ = (a+b)(a²-ab+b²) = (a+b)³-3ab(a+b)
a³-b³ = (a-b)(a²+ab+b²) = (a-b)³+3ab(a-b)

(a+b+c)² = a²+b²+c²+2(ab+bc+ca)
a³+b³+c³-3abc = (a+b+c)(a²+b²+c²-ab-bc-ca)

If a+b+c = 0: a³+b³+c³ = 3abc
```

### Important Results
```
If x + 1/x = k, then:
x² + 1/x² = k² - 2
x³ + 1/x³ = k³ - 3k
x⁴ + 1/x⁴ = (k²-2)² - 2
x - 1/x = ±√(k²-4)

If x - 1/x = k, then:
x² + 1/x² = k² + 2
x³ - 1/x³ = k³ + 3k

If x² + 1/x² = k, then:
x + 1/x = √(k+2)
x - 1/x = √(k-2)
```

### Quadratic Equations
```
ax² + bx + c = 0

Roots: x = [-b ± √(b²-4ac)] / 2a

Sum of roots (α+β) = -b/a
Product of roots (αβ) = c/a

Discriminant D = b²-4ac:
D > 0: Two real distinct roots
D = 0: Two equal real roots
D < 0: No real roots (imaginary)

D is a perfect square: Roots are rational
```

### Factor and Remainder Theorems
```
Factor Theorem: If f(a)=0, then (x-a) is a factor of f(x)
Remainder Theorem: When f(x) is divided by (x-a), remainder = f(a)
```

## Data Interpretation

### Types of Charts
```
1. Bar Graph: Compare quantities across categories
2. Line Graph: Show trends over time
3. Pie Chart: Show parts of a whole (total = 360° or 100%)
4. Table: Organized numerical data
5. Mixed Charts: Combination of above
```

### Pie Chart Formulas
```
Angle = (Value/Total) × 360°
Value = (Angle/360°) × Total
Percentage = (Angle/360°) × 100
Angle = (Percentage/100) × 360° = Percentage × 3.6°
```

### Key DI Skills
```
1. Read the question CAREFULLY — what exactly is asked?
2. Identify the relevant data from the chart/table
3. Calculate:
   - Percentage change: [(New-Old)/Old] × 100
   - Ratio: Direct division
   - Average: Sum/Count
   - Difference: Direct subtraction
4. Approximate when exact values aren't needed
5. Check answer choices — sometimes approximation is enough
```

### Speed Tips for DI
```
1. Round numbers for quick calculation
2. Use percentage shortcuts (10%, 5%, 1%)
3. Compare fractions by cross-multiplication
4. Use the answer choices to eliminate wrong options
5. Practice reading charts quickly — this saves time
```

## Last 10 Years PYQs

### PYQ 1 — SSC CHSL 2024
**Q.** If x+1/x=5, find x²+1/x²?
- (x+1/x)²=x²+2+1/x² → 25=x²+1/x²+2 → x²+1/x²=23
- Answer: **23** ✅

### PYQ 2 — SSC CHSL 2023
**Q.** If a+b+c=0, a²+b²+c²=14, find ab+bc+ca?
- (a+b+c)²=a²+b²+c²+2(ab+bc+ca)
- 0=14+2(ab+bc+ca) → ab+bc+ca=-7
- Answer: **-7** ✅

### PYQ 3 — SSC CHSL 2022
**Q.** Simplify: (0.5)³ + (0.3)³ + (0.2)³ / (0.5)² + (0.3)² + (0.2)² - 0.5×0.3 - 0.3×0.2 - 0.2×0.5
- Since 0.5+0.3+0.2=1.0, and a³+b³+c³-3abc=(a+b+c)(a²+b²+c²-ab-bc-ca)
- Numerator = a³+b³+c³ (if we add 3abc separately)
- Actually: (a³+b³+c³)/(a²+b²+c²-ab-bc-ca) when a+b+c=1
- = a³+b³+c³-3abc+3abc / (denominator) = 1×(denom)+3abc / denom = 1+3abc/denom
- Simplified answer: a+b+c = 1.0
- Answer: **1** ✅

### PYQ 4 — SSC CHSL 2021
**Q.** In a pie chart, if sector is 72°, what percentage?
- 72/360 × 100 = 20%
- Answer: **20%** ✅

### PYQ 5 — SSC CHSL 2020
**Q.** Roots of x²-5x+6=0?
- (x-2)(x-3)=0 → x=2 or x=3
