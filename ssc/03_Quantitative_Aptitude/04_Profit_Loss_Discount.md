## Basic Concepts

### Definitions
```
Cost Price (CP): Price at which an article is bought
Selling Price (SP): Price at which an article is sold
Marked Price (MP): Price written/labelled on the article (also called List Price)
Discount: Reduction given on Marked Price

Profit = SP - CP (when SP > CP)
Loss = CP - SP (when CP > SP)
```

---

## All Formulas

### Core Formulas
```
Profit = SP - CP
Loss = CP - SP

Profit% = (Profit/CP) × 100 = [(SP-CP)/CP] × 100
Loss% = (Loss/CP) × 100 = [(CP-SP)/CP] × 100

SP = CP × (1 + Profit%/100) → when profit
SP = CP × (1 - Loss%/100) → when loss

CP = SP × 100/(100 + Profit%)
CP = SP × 100/(100 - Loss%)

SP = CP × (100 + P%)/ 100
SP = CP × (100 - L%)/ 100
```

### Shortcut Multipliers
```
For 20% profit: SP = CP × 1.20 (multiply by 120/100)
For 15% loss: SP = CP × 0.85 (multiply by 85/100)
For 10% profit: SP = CP × 1.10
For 25% loss: SP = CP × 0.75
```

## Discount

### Formulas
```
Discount = MP - SP
Discount% = (Discount/MP) × 100 = [(MP-SP)/MP] × 100
SP = MP × (1 - Discount%/100)
SP = MP × (100 - D%)/100
```

### Successive Discounts
```
Two discounts of d₁% and d₂%:
Net discount = d₁ + d₂ - (d₁×d₂/100)

Example: 20% and 10% successive discount:
Net = 20 + 10 - (200/100) = 28%

SP after successive discounts:
SP = MP × (1 - d₁/100) × (1 - d₂/100)
```

## Marked Price Problems

### Finding Profit% When Discount% and Markup% Given
```
If MP is x% above CP and discount is d%:

SP = MP(1 - d/100) = CP(1 + x/100)(1 - d/100)

Profit% = [(1 + x/100)(1 - d/100) - 1] × 100

Example: Marked 40% above CP, discount 10%:
SP = CP × 1.4 × 0.9 = CP × 1.26
Profit = 26%
```

### Key Relationship
```
MP/CP = (100 + Profit%)/(100 - Discount%)

Example: 20% profit with 10% discount:
MP/CP = 120/90 = 4/3
So MP is 33.33% above CP
```

### Break-Even (No Profit No Loss)
```
SP = CP → Profit = 0, Loss = 0
This happens when: Markup% = Discount% / (1 - Discount%/100)

Example: 20% discount → needs 25% markup for break-even
(since 1.25 × 0.8 = 1.0)
```

## Dishonest Dealer

### Using False Weights
```
Gain% = [(True Weight - False Weight) / False Weight] × 100

Example: A shopkeeper uses 900g weight instead of 1kg:
Gain% = [(1000-900)/900] × 100 = (100/900) × 100 = 11.11%

Combined with other profit:
If he also marks up by x% and uses false weight:
Total gain = Combined effect of both
```

### Selling at CP but Using False Weight
```
If dealer sells at CP but uses x grams instead of 1000g:
Profit% = [(1000-x)/x] × 100

If uses 800g weight:
Profit = [(1000-800)/800] × 100 = 25%
```

## Partnership

### Simple Partnership (Same Time)
```
Profit is divided in the ratio of investments.

A invests ₹3000, B invests ₹5000.
Profit ratio = 3000 : 5000 = 3 : 5

If total profit = ₹16000:
A's share = 16000 × 3/8 = ₹6000
B's share = 16000 × 5/8 = ₹10000
```

### Compound Partnership (Different Times)
```
Profit ratio = (Investment × Time) for each partner

A invests ₹3000 for 12 months, B invests ₹4000 for 9 months.
Ratio = 3000×12 : 4000×9 = 36000 : 36000 = 1 : 1

Equal profit sharing!
```

### Working + Sleeping Partner
```
Working partner gets salary/commission FIRST.
Remaining profit is divided by investment ratio.

A (working) gets ₹2000 salary + share of profit
B (sleeping) gets only share of profit
```

## Important Concepts

### If SP of x articles = CP of y articles
```
Profit% = [(y-x)/x] × 100

Example: SP of 20 articles = CP of 25 articles
Profit% = [(25-20)/20] × 100 = 25%

Example: CP of 15 articles = SP of 12 articles
Profit% = [(15-12)/12] × 100 = 25%
```

### Two Articles Sold at Same Price (One at Profit, One at Loss)
```
If two articles sold at same SP:
One at x% profit, other at x% loss:

Overall there is ALWAYS a LOSS.
Loss% = (x²/100)% = x²/100 %

Example: Two articles sold at ₹500 each.
One at 20% profit, one at 20% loss.
Overall loss = 20²/100 = 4%
```

## Tips and Tricks

### ⚡ Quick Shortcuts
```
1. CP=100 trick: Assume CP=100, then calculate SP directly
2. For discount questions: MP is the base, not CP
3. Profit% is ALWAYS on CP
4. Discount% is ALWAYS on MP

Common fraction shortcuts:
10% profit → SP = 11/10 of CP
20% profit → SP = 6/5 of CP
25% profit → SP = 5/4 of CP
33.33% profit → SP = 4/3 of CP
50% profit → SP = 3/2 of CP
```
