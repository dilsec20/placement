## 2D Figures — Area & Perimeter

| Shape | Area | Perimeter |
|-------|------|-----------|
| **Square** (side a) | a² | 4a |
| **Rectangle** (l, b) | l × b | 2(l+b) |
| **Triangle** (base b, height h) | ½bh | a+b+c |
| **Equilateral Triangle** (side a) | (√3/4)a² | 3a |
| **Right Triangle** (b, h) | ½bh | b+h+√(b²+h²) |
| **Isosceles Triangle** (equal sides a, base b) | (b/4)√(4a²-b²) | 2a+b |
| **Circle** (radius r) | πr² | 2πr |
| **Semicircle** (radius r) | πr²/2 | πr + 2r |
| **Ring/Annulus** (R, r) | π(R²-r²) | 2π(R+r) |
| **Parallelogram** (base b, height h) | b × h | 2(a+b) |
| **Rhombus** (diagonals d₁, d₂) | ½d₁d₂ | 4a = 2√(d₁²+d₂²) |
| **Trapezium** (parallel sides a,b; height h) | ½(a+b)h | a+b+c+d |
| **Sector** (radius r, angle θ°) | (θ/360)πr² | 2r + (θ/360)×2πr |
| **Quadrilateral** (diagonal d; h₁, h₂) | ½d(h₁+h₂) | Sum of sides |

### Special Formulas
```
Heron's formula: Area = √[s(s-a)(s-b)(s-c)], s=(a+b+c)/2

Path around rectangle (width w):
Outer path: Area = 2w(l+b+2w) or 2w(l+b) if inner
Inner path: Area = 2w(l+b-2w)

Diagonal of square: d = a√2 → a = d/√2
Diagonal of rectangle: d = √(l²+b²)
Side of rhombus: a = ½√(d₁²+d₂²)
```

## 3D Figures — Volume & Surface Area

### Cube (side a)
```
Volume = a³
TSA (Total Surface Area) = 6a²
LSA (Lateral Surface Area) = 4a²
Diagonal = a√3
```

### Cuboid (l, b, h)
```
Volume = l × b × h
TSA = 2(lb + bh + lh)
LSA = 2h(l + b)
Diagonal = √(l² + b² + h²)
```

### Cylinder (radius r, height h)
```
Volume = πr²h
CSA (Curved Surface Area) = 2πrh
TSA = 2πr(r + h)
```

### Cone (radius r, height h, slant height l)
```
Volume = ⅓πr²h
CSA = πrl
TSA = πr(r + l)
Slant height: l = √(r² + h²)
```

### Sphere (radius r)
```
Volume = (4/3)πr³
Surface Area = 4πr²
```

### Hemisphere (radius r)
```
Volume = (2/3)πr³
CSA = 2πr²
TSA = 3πr² (curved + flat base)
```

### Frustum of Cone (R, r, h)
```
Volume = (πh/3)(R² + r² + Rr)
CSA = π(R+r)l where l = √[h²+(R-r)²]
TSA = π(R+r)l + πR² + πr²
```

### Prism
```
Volume = Base area × height
LSA = Perimeter of base × height
TSA = LSA + 2 × Base area
```

### Pyramid
```
Volume = ⅓ × Base area × height
LSA = ½ × Perimeter of base × Slant height
TSA = LSA + Base area
```

- Answer: **1540 cm³** ✅

### PYQ 2 — SSC CHSL 2023
**Q.** TSA of cube with side 5 cm?
- 6×25 = 150 cm²
- Answer: **150 cm²** ✅

### PYQ 3 — SSC CHSL 2022
**Q.** Area of trapezium, parallel sides 10 and 6, height 8?
- ½(10+6)×8 = ½×16×8 = 64 cm²
- Answer: **64 cm²** ✅

### PYQ 4 — SSC CHSL 2021
**Q.** Volume of sphere, r=3?
- 4/3 × 22/7 × 27 = 4×22×27/(3×7) = 2376/21 ≈ 113.14 cm³
- Answer: **113.14 cm³** (or 36π) ✅

### PYQ 5 — SSC CHSL 2020
**Q.** Cone, r=3, h=4. Slant height and volume?
- l = √(9+16) = 5; V = ⅓×π×9×4 = 12π
- Answer: **l=5, V=12π cm³** ✅
