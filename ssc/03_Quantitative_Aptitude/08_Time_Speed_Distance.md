## Basic Formulas

```
Speed = Distance / Time
Distance = Speed × Time
Time = Distance / Speed

Units: Speed in km/h or m/s, Distance in km or m, Time in hours or seconds
```

---

## Unit Conversions

```
km/h to m/s: Multiply by 5/18
m/s to km/h: Multiply by 18/5

1 km/h = 5/18 m/s
1 m/s = 18/5 km/h = 3.6 km/h

Quick conversions:
18 km/h = 5 m/s
36 km/h = 10 m/s
54 km/h = 15 m/s
72 km/h = 20 m/s
90 km/h = 25 m/s
108 km/h = 30 m/s

1 km = 1000 m
1 hour = 3600 seconds
1 mile ≈ 1.6 km
```

## Average Speed

### Formula
```
Average Speed = Total Distance / Total Time

IMPORTANT: Average speed ≠ Average of speeds!

Case 1: Same distance, different speeds
If speeds are a and b for equal distances:
Average speed = 2ab/(a+b) (Harmonic mean)

Case 2: Same time, different speeds
If speeds are a and b for equal times:
Average speed = (a+b)/2 (Arithmetic mean)
```

### Examples
```
Q: A man goes to office at 40 km/h and returns at 60 km/h. Average speed?
Same distance → Average = 2×40×60/(40+60) = 4800/100 = 48 km/h
(NOT 50 km/h!)

Q: A car travels at 30 km/h for 2 hours and 50 km/h for 3 hours.
Total distance = 30×2 + 50×3 = 60+150 = 210 km
Total time = 2+3 = 5 hours
Average speed = 210/5 = 42 km/h
```

## Relative Speed

### Same Direction (Chasing)
```
Relative speed = |Speed₁ - Speed₂|
(Faster - Slower)

Time to catch up = Gap / Relative speed
```

### Opposite Direction (Approaching)
```
Relative speed = Speed₁ + Speed₂

Time to meet = Gap / Relative speed
```

## Train Problems

### Key Formulas
```
1. Train crossing a pole/person (point object):
   Time = Length of train / Speed of train

2. Train crossing a bridge/platform:
   Time = (Length of train + Length of bridge) / Speed of train

3. Two trains crossing each other (opposite direction):
   Time = (L₁ + L₂) / (S₁ + S₂)

4. Two trains crossing each other (same direction):
   Time = (L₁ + L₂) / |S₁ - S₂|

5. Train crossing a person moving:
   Same direction: Time = L_train / (S_train - S_person)
   Opposite direction: Time = L_train / (S_train + S_person)
```

### Examples
```
Q: A 200m train at 72 km/h crosses a pole in how much time?
Speed = 72 × 5/18 = 20 m/s
Time = 200/20 = 10 seconds

Q: A 300m train at 54 km/h crosses a 200m platform in?
Speed = 54 × 5/18 = 15 m/s
Time = (300+200)/15 = 500/15 = 33.33 seconds

Q: Trains 150m and 250m at 60 km/h and 40 km/h (opposite direction)?
Relative speed = (60+40) × 5/18 = 100 × 5/18 = 250/9 m/s
Time = (150+250)/(250/9) = 400 × 9/250 = 14.4 seconds
```

## Boat and Stream

### Key Concepts
```
Downstream (with stream): Speed = Boat + Stream = (u + v)
Upstream (against stream): Speed = Boat - Stream = (u - v)

Where u = speed of boat in still water, v = speed of stream

Speed of boat in still water = (Downstream + Upstream) / 2
Speed of stream = (Downstream - Upstream) / 2

u = (D + U) / 2
v = (D - U) / 2
```

### Examples
```
Q: Boat speed in still water = 10 km/h. Stream = 2 km/h.
   Time to go 24 km downstream and return?

Downstream speed = 10+2 = 12 km/h → Time = 24/12 = 2 hours
Upstream speed = 10-2 = 8 km/h → Time = 24/8 = 3 hours
Total time = 2+3 = 5 hours

Q: Downstream 15 km in 1 hour, upstream 15 km in 3 hours. Find boat & stream speed.
Downstream speed = 15 km/h, Upstream speed = 5 km/h
Boat = (15+5)/2 = 10 km/h
Stream = (15-5)/2 = 5 km/h
```

## Race Problems

### Key Concepts
```
In a race of x meters:
"A beats B by d meters" → When A finishes x meters, B has run (x-d) meters
"A beats B by t seconds" → A finishes t seconds before B
"A gives B a head start of h meters" → B starts h meters ahead

Speed ratio = Distance ratio (in same time)
If A beats B by 20m in a 100m race:
Speed ratio = 100:80 = 5:4

Dead heat = Both finish at same time (tie)
```

### Examples
```
Q: In 100m race, A beats B by 10m. In same race, B beats C by 10m.
   By how much does A beat C?

When A runs 100m, B runs 90m.
When B runs 100m, C runs 90m.
When B runs 90m, C runs 90×90/100 = 81m.
When A runs 100m, C runs 81m.
A beats C by 100-81 = 19m
```

## Tips and Tricks

### ⚡ Quick Shortcuts
```
1. km/h to m/s: × 5/18 (divide by 3.6)
2. m/s to km/h: × 18/5 (multiply by 3.6)
3. Same distance, diff speed: Avg = 2ab/(a+b)
4. Train + pole: Time = L/S
5. Train + platform: Time = (L_train + L_platform)/S
6. Opposite trains: Add speeds
7. Same direction trains: Subtract speeds
8. Boat still water = (downstream + upstream)/2
9. Stream speed = (downstream - upstream)/2
```

## Last 10 Years PYQs

### PYQ 1 — SSC CHSL 2024
**Q.** A 250m train at 90 km/h crosses a pole in?
- 90 × 5/18 = 25 m/s; Time = 250/25 = 10 sec
- Answer: **10 seconds** ✅

### PYQ 2 — SSC CHSL 2023
**Q.** Goes at 40 km/h, returns at 60 km/h. Average speed?
- 2×40×60/100 = 48
- Answer: **48 km/h** ✅

### PYQ 3 — SSC CHSL 2022
**Q.** Boat speed 12 km/h, stream 4 km/h. Time for 32 km upstream?
- Upstream = 12-4 = 8 km/h; Time = 32/8 = 4 hours
- Answer: **4 hours** ✅

### PYQ 4 — SSC CHSL 2021
**Q.** Two trains 200m and 300m, speeds 60 and 40 km/h, opposite direction. Crossing time?
- Relative = (60+40)×5/18 = 250/9 m/s
- Time = 500/(250/9) = 18 sec
- Answer: **18 seconds** ✅

### PYQ 5 — SSC CHSL 2020
**Q.** A 100m race: A beats B by 20m, B beats C by 10m. A beats C by?
- A:B speed = 100:80=5:4; B:C=100:90=10:9
- A:C = 50:36 = 25:18; A beats C by 100-72=28m? 
- Or: When A=100, B=80. When B=100, C=90. When B=80, C=72. A beats C by 28m.
- Answer: **28m** ✅

> **Final Tip:** Convert to m/s for train problems, km/h for journey problems. Remember: opposite direction = ADD speeds, same direction = SUBTRACT speeds. For average speed with same distance, use 2ab/(a+b), NOT (a+b)/2! 🚂
