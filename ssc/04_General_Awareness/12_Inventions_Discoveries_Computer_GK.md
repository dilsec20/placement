## Computer Generations & Fundamental Architecture

### The Five Generations of Computers
| Generation | Time Period | Core Switching Technology | Main Memory / Secondary | Languages Used | Examples |
|------------|-------------|---------------------------|-------------------------|----------------|----------|
| **1st Gen** | 1940–1956 | **Vacuum Tubes (Thermionic Valves)** | Magnetic Drums / Magnetic Tapes | Machine language (Binary: 0s & 1s) | ENIAC, EDVAC, UNIVAC I, IBM 701 |
| **2nd Gen** | 1956–1963 | **Transistors** (invented at Bell Labs by Bardeen, Brattain, Shockley) | Magnetic Core Memory / Magnetic Disks | Assembly language, early High-Level (FORTRAN, COBOL) | IBM 1401, CDC 1604, PDP-8 |
| **3rd Gen** | 1964–1971 | **Integrated Circuits (ICs)** (invented by Jack Kilby & Robert Noyce; Small/Medium Scale Integration) | Semiconductor Memory | High-Level languages (BASIC, Pascal, C) | IBM System/360, PDP-11 |
| **4th Gen** | 1971–Present| **Microprocessors (VLSI & LSI)** (Intel 4004 was 1st microprocessor in 1971) | Semiconductor RAM / ROM, HDD, SSD | C++, Java, Python, SQL, GUI | Apple II, IBM PC, Modern Desktops/Laptops |
| **5th Gen** | Present & Beyond | **Artificial Intelligence (AI), ULSI**, Quantum Computing | Optical Storage, Cloud, High-speed NVMe | Natural Language Processing, Neural Networks | Supercomputers, Quantum computers, Robotics |

### Central Processing Unit (CPU)
Known as the **"Brain of the Computer"**.
```
Central Processing Unit (CPU)
├── 1. Arithmetic Logic Unit (ALU): Performs arithmetic (+, -, *, /) and logical comparisons (<, >, ==, AND, OR).
├── 2. Control Unit (CU): "Traffic cop" of CPU; directs flow of data and instructions between CPU and other devices.
└── 3. Registers: High-speed, small-capacity temporary storage locations directly inside the CPU:
     ├── Program Counter (PC): Holds address of next instruction to be executed.
     ├── Instruction Register (IR): Holds current instruction being executed.
     ├── Memory Address Register (MAR): Holds memory address being accessed.
     ├── Memory Buffer / Data Register (MBR/MDR): Holds data read from or written to memory.
     └── Accumulator (AC): Stores intermediate results of ALU calculations.
```

- **Clock Speed:** Speed at which CPU executes cycles, measured in **Gigahertz (GHz)** or Megahertz (MHz).
- **System Bus:** Internal communication channel consisting of **Data Bus** (bidirectional), **Address Bus** (unidirectional from CPU), and **Control Bus**.

## Computer Memory & Storage Hierarchy

### Memory Hierarchy (Speed vs Cost vs Capacity)
$$\text{Registers (Fastest, Smallest, Costliest)} > \text{Cache Memory} > \text{Primary Memory (RAM/ROM)} > \text{Secondary Storage (Slowest, Largest, Cheapest)}$$

```
Computer Memory
├── Primary Memory (Main Memory / Internal)
│   ├── RAM (Random Access Memory) — VOLATILE (Data lost when power turned off)
│   │   ├── SRAM (Static RAM): Made of flip-flops; faster, does not need periodic refreshing; used in CACHE.
│   │   └── DRAM (Dynamic RAM): Made of capacitors & transistors; needs periodic refreshing; used as MAIN RAM.
│   └── ROM (Read Only Memory) — NON-VOLATILE (Permanent memory; stores firmware/BIOS)
│       ├── PROM (Programmable ROM): Written once by user using PROM burner.
│       ├── EPROM (Erasable PROM): Erased by exposing to strong Ultraviolet (UV) light.
│       └── EEPROM (Electrically Erasable PROM): Erased electrically; basis of FLASH MEMORY.
└── Secondary Memory (Auxiliary / External / Permanent Storage)
    ├── Magnetic: Hard Disk Drive (HDD), Magnetic Tape, Floppy Disk (1.44 MB standard size).
    ├── Optical: CD-ROM (700 MB), DVD (4.7 GB), Blu-ray Disc (25 GB single layer, 50 GB dual layer).
    └── Solid-State: SSD (Solid State Drive), USB Flash Drive (Pen drive), SD Card (uses NAND flash).
```

### Units of Computer Memory Measurement
- **1 Bit** = Binary digit (0 or 1) — Smallest unit of data
- **1 Nibble** = **4 Bits**
- **1 Byte** = **8 Bits** (Can represent 1 ASCII character)
- **1 Kilobyte (KB)** = $1024\text{ Bytes} = 2^{10}\text{ Bytes}$
- **1 Megabyte (MB)** = $1024\text{ KB} = 2^{20}\text{ Bytes}$
- **1 Gigabyte (GB)** = $1024\text{ MB} = 2^{30}\text{ Bytes}$
- **1 Terabyte (TB)** = $1024\text{ GB} = 2^{40}\text{ Bytes}$
- **1 Petabyte (PB)** = $1024\text{ TB}$
- **1 Exabyte (EB)** = $1024\text{ PB}$
- **1 Zettabyte (ZB)** = $1024\text{ EB}$
- **1 Yottabyte (YB)** = $1024\text{ ZB}$

## Input, Output & Hardware Devices

### Input Devices
- **Keyboard:** Standard layout is **QWERTY** (invented by Christopher Latham Sholes). Standard desktop keyboard has 101–104 keys.
- **Mouse:** Pointing device invented by **Douglas Engelbart** (1964).
- **Scanner:** Converts physical documents/images into digital raster format.
- **OCR (Optical Character Recognition):** Scans printed/handwritten text and converts it into editable digital text.
- **OMR (Optical Mark Recognition):** Detects pencil/pen marks on answer sheets.
- **MICR (Magnetic Ink Character Recognition):** Reads special magnetic ink characters printed on bank cheques (9-digit code: first 3 city, middle 3 bank, last 3 branch).
- **Barcode Reader & QR Code Reader:** Quick Response (QR) code is a 2D matrix barcode invented by Denso Wave in 1994.

### Output Devices
- **Monitors (VDU - Visual Display Unit):** CRT (Cathode Ray Tube), LCD (Liquid Crystal Display), LED (Light Emitting Diode), OLED (Organic LED). Screen resolution measured in **pixels**; aspect ratio = width:height.
- **Printers:**
  - **Impact Printers:** Physical strike against inked ribbon (noisy, slower). Examples: **Dot Matrix Printer**, Daisy Wheel, Line Printer.
  - **Non-Impact Printers:** No mechanical strike (fast, quiet, high quality). Examples: **Laser Printer** (uses powdered toner, drum, laser beam; fastest page printer), **Inkjet Printer** (uses liquid ink nozzles), Thermal Printer (uses heat-sensitive paper; used in billing machines/ATMs).
  - Printer resolution measured in **DPI (Dots Per Inch)**; printing speed measured in **PPM (Pages Per Minute)**.
- **Plotter:** Produces high-precision large vector architectural blueprints, maps, and engineering drawings.

## Operating Systems, Software & File Extensions

### Types of Software
1. **System Software:** Controls hardware operations and provides a platform for application software.
   - *Examples:* Operating Systems (OS), Device Drivers, BIOS firmware, Utility programs (Antivirus, Disk Defragmenter).
2. **Application Software:** Designed to perform specific end-user tasks.
   - *Examples:* MS Word, Excel, Web browsers (Chrome, Edge), Media players.

### Operating Systems (OS)
- Core component: **Kernel** (manages CPU, memory, hardware interactions).
- User Interface: **CLI / CUI** (Command Line Interface, e.g., MS-DOS, Linux terminal) vs **GUI** (Graphical User Interface, e.g., Windows, macOS).
- **Open Source OS:** Linux (created by Linus Torvalds, 1991), Android, FreeBSD.
- **Proprietary OS:** Microsoft Windows, macOS, iOS.
- **First sector of hard drive read during boot-up:** **Master Boot Record (MBR)**.
- **Cold Booting:** Starting computer from a completely powered-off state.
- **Warm Booting:** Restarting computer using Ctrl + Alt + Delete or software reboot while power is already on.

## Computer Networking, Internet & Protocols

### Network Coverage Classification
- **PAN (Personal Area Network):** Range $\approx 10\text{ metres}$ (e.g., Bluetooth, wireless mouse).
- **LAN (Local Area Network):** Confined to a single room, building, or office campus (uses Ethernet cables, Wi-Fi).
- **MAN (Metropolitan Area Network):** Covers an entire city or town (e.g., cable TV network).
- **WAN (Wide Area Network):** Covers vast geographical areas across countries/continents (e.g., the **Internet**).

### Network Topologies
- **Star Topology:** All nodes connected directly to a central hub/switch. Most common in modern LANs; single node failure does not affect the rest.
- **Bus Topology:** All nodes connected along a single central communication backbone wire terminated at ends.
- **Ring Topology:** Each computer connected to two neighboring computers forming a closed loop; token passing.
- **Mesh Topology:** Every node connected directly to every other node. **Most redundant and reliable**, but most expensive.

### The OSI 7-Layer Model (Mnemonics: *Please Do Not Throw Sausage Pizza Away*)
1. **Physical Layer** (Bits: cables, hubs, repeaters)
2. **Data Link Layer** (Frames: switches, MAC address, bridges)
3. **Network Layer** (Packets: routers, IP address)
4. **Transport Layer** (Segments: TCP, UDP, end-to-end reliability, flow control)
5. **Session Layer** (Dialog control, session establishment)
6. **Presentation Layer** (Data encryption, compression, formatting)
7. **Application Layer** (User interface: HTTP, FTP, SMTP, DNS)

### Crucial Networking Protocols
- **IP Address:**
  - **IPv4:** **32-bit address**, written in decimal as 4 octets separated by dots (e.g., `192.168.1.1`). Total addresses $\approx 4.3\text{ billion}$.
  - **IPv6:** **128-bit address**, written in hexadecimal as 8 groups of 4 hex digits separated by colons.
- **MAC Address (Media Access Control):** Permanent hardware physical address embedded in Network Interface Card (NIC); **48 bits (6 bytes)**, written in hex (e.g., `00:1A:2B:3C:4D:5E`).
- **HTTP / HTTPS:** HyperText Transfer Protocol (Port 80); HTTPS is encrypted with SSL/TLS (Port 443).
- **FTP:** File Transfer Protocol (Port 20/21) for uploading/downloading files.
- **SMTP:** Simple Mail Transfer Protocol (Port 25) for **sending emails**.
- **POP3 / IMAP:** Post Office Protocol 3 (Port 110) / Internet Message Access Protocol (Port 143) for **receiving / retrieving emails**.
- **DNS (Domain Name System):** Resolves human-friendly domain names (e.g., `www.google.com`) into IP addresses.
- **DHCP:** Dynamic Host Configuration Protocol; automatically assigns IP addresses to devices on a network.

## Cybersecurity, Threats & Malware

- **Virus (Vital Information Resources Under Siege):** Malicious software program that attaches to legitimate files and replicates when executed.
- **Worm:** Standalone malicious software that self-replicates across networks **without needing a host file or human intervention**.
- **Trojan Horse:** Malicious program disguised as legitimate or useful software (does not self-replicate).
- **Ransomware:** Encrypts user's files and demands ransom money (usually cryptocurrency) for decryption key (e.g., *WannaCry*, *Petya*).
- **Spyware:** Secretly tracks and records user activities, passwords, and sensitive information (e.g., *Pegasus*, Keyloggers).
- **Phishing:** Fraudulent attempt to steal sensitive personal information (passwords, credit card numbers) through deceptive emails or fake websites.
- **Firewall:** Hardware or software security device that monitors and filters incoming and outgoing network traffic based on security rules.
- **First PC Virus:** **Brain Virus** (written in 1986 by Farooq Alvi brothers in Pakistan for MS-DOS).

## Last 10 Years PYQs with Detailed Explanations

### PYQ 1 — SSC CHSL 2024
**Q.** Which keyboard shortcut is used to insert a hyperlink in Microsoft Word?
- A) Ctrl + H
- B) Ctrl + K
- C) Ctrl + L
- D) Ctrl + P
- **Answer:** **B) Ctrl + K** ✅
- *Explanation:* Ctrl + K opens the Insert Hyperlink dialog box. Ctrl + H opens Find and Replace; Ctrl + L left-aligns text.

### PYQ 2 — SSC CHSL 2023
**Q.** Which generation of computers used Transistors for the first time replacing vacuum tubes?
- A) First Generation
- B) Second Generation
- C) Third Generation
- D) Fourth Generation
- **Answer:** **B) Second Generation (1956–1963)** ✅
- *Explanation:* Second-generation computers replaced fragile vacuum tubes with solid-state transistors, making them smaller, faster, cheaper, and more energy-efficient.

### PYQ 3 — SSC CHSL 2023
**Q.** What does the acronym "BIOS" stand for in computer systems?
- A) Basic Input Operating System
- B) Binary Input Output System
- C) Basic Input / Output System
- D) Base Interface Operating Software
- **Answer:** **C) Basic Input / Output System** ✅
- *Explanation:* BIOS is the firmware stored in non-volatile ROM that initializes hardware and performs Power-On Self-Test (POST) during booting.

### PYQ 4 — SSC CHSL 2022
**Q.** How many bits are there in an IPv4 address?
- A) 16 bits
- B) 32 bits
- C) 64 bits
- D) 128 bits
- **Answer:** **B) 32 bits** ✅
- *Explanation:* IPv4 addresses are 32 bits long (4 bytes), represented as 4 decimal octets (e.g., 172.16.254.1). IPv6 addresses are 128 bits long.

### PYQ 5 — SSC CHSL 2022
**Q.** Which of the following is an example of volatile memory?
- A) ROM
- B) Hard Disk
- C) RAM
- D) Pen Drive
- **Answer:** **C) RAM (Random Access Memory)** ✅
- *Explanation:* RAM is volatile; its stored information is lost immediately when the power supply is switched off. ROM, SSD, and HDD are non-volatile.

### PYQ 6 — SSC CHSL 2021
**Q.** Who invented the World Wide Web (WWW) in 1989?
- A) Bill Gates
- B) Tim Berners-Lee
- C) Steve Jobs
- D) Charles Babbage
- **Answer:** **B) Tim Berners-Lee** ✅
- *Explanation:* British scientist Tim Berners-Lee invented the World Wide Web while working at CERN in 1989.

### PYQ 7 — SSC CHSL 2020
**Q.** In Microsoft Excel, how many rows are there in a worksheet?
- A) 65,536
- B) 1,048,576
- C) 524,288
- D) 2,097,152
- **Answer:** **B) 1,048,576** ✅
- *Explanation:* From Excel 2007 onwards, each worksheet has 1,048,576 rows and 16,384 columns (up to XFD).

### PYQ 8 — SSC CHSL 2019
**Q.** Which of the following malware self-replicates across computer networks without requiring a host program?
- A) Trojan Horse
- B) Computer Worm
- C) Macro Virus
- D) Spyware
- **Answer:** **B) Computer Worm** ✅
- *Explanation:* A worm is a standalone malware that actively clones and spreads itself across networks, consuming network bandwidth without human action.

### PYQ 9 — SSC CHSL 2018
**Q.** Which function key is pressed in Microsoft Office to check Spelling and Grammar?
- A) F2
- B) F5
- C) F7
- D) F12
- **Answer:** **C) F7** ✅
- *Explanation:* F7 triggers the Spelling and Grammar check tool. Shift + F7 opens the Thesaurus; F12 opens Save As.

### PYQ 10 — SSC CHSL 2017
**Q.** Which protocol is primarily used for sending outgoing emails across the Internet?
- A) POP3
- B) IMAP
- C) SMTP
- D) FTP
- **Answer:** **C) SMTP (Simple Mail Transfer Protocol)** ✅
- *Explanation:* SMTP is used to push/send outgoing emails from client to server. POP3 and IMAP are used to retrieve/download emails from the server.
