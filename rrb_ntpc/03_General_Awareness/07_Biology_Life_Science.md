## 📖 Complete Theory

### 1. Cell Biology

| Feature | Plant Cell | Animal Cell |
|---------|-----------|-------------|
| Cell Wall | Present (cellulose) | Absent |
| Chloroplast | Present | Absent |
| Vacuole | Large, central | Small, multiple |
| Centrioles | Absent | Present |
| Shape | Fixed (rectangular) | Variable |

**Cell Organelles:**
| Organelle | Function |
|-----------|----------|
| Nucleus | Controls cell activities, contains DNA |
| Mitochondria | Powerhouse of cell (ATP production) |
| Ribosome | Protein synthesis |
| Endoplasmic Reticulum | Transport within cell |
| Golgi Body | Packaging & secretion |
| Lysosome | Digestion (Suicide bags) |
| Chloroplast | Photosynthesis (plants) |

### 2. Human Body Systems

#### Digestive System
Mouth → Esophagus → Stomach → Small Intestine → Large Intestine → Rectum → Anus

| Organ | Function | Enzyme/Juice |
|-------|----------|-------------|
| Mouth | Chewing, starch digestion | Salivary amylase (ptyalin) |
| Stomach | Protein digestion | HCl, Pepsin |
| Liver | Produces bile | Bile (emulsifies fats) |
| Pancreas | Produces enzymes | Trypsin, lipase, amylase |
| Small Intestine | Absorption of nutrients | Villi |
| Large Intestine | Water absorption | — |

**Largest gland:** Liver | **Largest organ:** Skin

#### Circulatory System
| Feature | Detail |
|---------|--------|
| Heart chambers | 4 (2 atria + 2 ventricles) |
| Blood types | A, B, AB, O |
| Universal donor | O (Rh−) |
| Universal recipient | AB (Rh+) |
| RBC (Red Blood Cells) | Carry oxygen (hemoglobin), no nucleus |
| WBC (White Blood Cells) | Fight infection (immunity) |
| Platelets | Blood clotting |
| Normal BP | 120/80 mmHg |

#### Respiratory System
Nose → Pharynx → Larynx → Trachea → Bronchi → Bronchioles → Alveoli

- **Gas exchange** occurs in **alveoli** (O₂ in, CO₂ out)
- **Diaphragm** controls breathing

#### Nervous System
| Part | Function |
|------|----------|
| Brain | Control center (cerebrum, cerebellum, medulla) |
| Spinal Cord | Relay signals, reflex actions |
| Cerebrum | Thinking, memory, intelligence (largest part) |
| Cerebellum | Balance & coordination |
| Medulla | Involuntary actions (breathing, heartbeat) |

#### Excretory System
- **Kidneys** filter blood → produce urine
- Functional unit: **Nephron**
- Urine: Water + Urea + Salts

#### Skeletal System
- Total bones in adult: **206**
- Smallest bone: **Stapes** (ear)
- Largest bone: **Femur** (thigh)

### 3. Diseases

#### Bacterial Diseases
| Disease | Caused By | Affected Organ |
|---------|-----------|---------------|
| Tuberculosis (TB) | Mycobacterium | Lungs |
| Cholera | Vibrio cholerae | Intestine |
| Typhoid | Salmonella typhi | Intestine |
| Plague | Yersinia pestis | Lungs/lymph |
| Tetanus | Clostridium tetani | Muscles |
| Leprosy | Mycobacterium leprae | Skin/nerves |
| Pneumonia | Streptococcus | Lungs |

#### Viral Diseases
| Disease | Virus | Spread By |
|---------|-------|-----------|
| COVID-19 | SARS-CoV-2 | Respiratory droplets |
| Dengue | Dengue virus | Aedes mosquito |
| Rabies | Rabies virus | Dog/animal bite |
| Polio | Polio virus | Contaminated water |
| AIDS | HIV | Blood, sexual contact |
| Influenza (Flu) | Influenza virus | Respiratory |
| Hepatitis B | HBV | Blood |
| Chickenpox | Varicella zoster | Airborne |

#### Deficiency Diseases
| Disease | Deficiency | Symptom |
|---------|-----------|---------|
| Scurvy | Vitamin C | Bleeding gums |
| Rickets | Vitamin D | Weak/bent bones (children) |
| Night blindness | Vitamin A | Can't see in dark |
| Beri-beri | Vitamin B1 (Thiamine) | Weakness, nerve damage |
| Pellagra | Vitamin B3 (Niacin) | Dermatitis, diarrhea |
| Anemia | Iron | Fatigue, pale skin |
| Goiter | Iodine | Swollen thyroid gland |
| Kwashiorkor | Protein | Swollen belly (children) |
| Marasmus | Protein + Calories | Extreme wasting |

### 4. Vitamins

| Vitamin | Chemical Name | Source | Soluble In |
|---------|--------------|--------|-----------|
| A | Retinol | Carrot, papaya, milk | Fat |
| B1 | Thiamine | Cereals, pulses | Water |
| B2 | Riboflavin | Milk, eggs | Water |
| B3 | Niacin | Meat, peanuts | Water |
| B12 | Cobalamin | Meat, fish, eggs | Water |
| C | Ascorbic acid | Citrus fruits, amla | Water |
| D | Calciferol | Sunlight, fish oil | Fat |
| E | Tocopherol | Nuts, seeds, oils | Fat |
| K | Phylloquinone | Green vegetables | Fat |

**Fat-soluble:** A, D, E, K (mnemonic: **ADEK**)
**Water-soluble:** B, C

### 5. Plant Biology

| Process | Description |
|---------|-------------|
| Photosynthesis | 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂ (in chloroplast) |
| Respiration | C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + Energy |
| Transpiration | Loss of water through stomata |

### 6. Genetics Basics

- **DNA** = Deoxyribonucleic Acid (genetic material)
- **Gene** = Unit of heredity (segment of DNA)
- **Chromosome** = Humans have 46 (23 pairs)
- Sex chromosomes: XX = Female, XY = Male
- Father determines the sex of the child (X or Y sperm)

### 7. Ecology

- **Food Chain:** Grass → Grasshopper → Frog → Snake → Eagle
- **Producers** = Plants | **Primary consumers** = Herbivores | **Secondary** = Carnivores
- **Decomposers** = Fungi, bacteria
