## 📖 Complete Theory

### 1. Computer Basics

| Term | Definition |
|------|-----------|
| Computer | Electronic device that processes data into information |
| Data | Raw facts (input) |
| Information | Processed data (output) |
| Hardware | Physical components |
| Software | Programs/instructions |

**Block Diagram:** Input → Processing (CPU) → Output (with Storage & Memory)

### 2. Generations of Computers

| Generation | Period | Technology | Example |
|-----------|--------|-----------|---------|
| 1st | 1940-1956 | Vacuum Tubes | ENIAC, UNIVAC |
| 2nd | 1956-1963 | Transistors | IBM 7094 |
| 3rd | 1964-1971 | Integrated Circuits (ICs) | IBM 360 |
| 4th | 1971-Present | Microprocessors (VLSI) | Personal Computers |
| 5th | Present+ | AI, Parallel Processing | Robotics, AI |

### 3. Types of Computers

| By Size | Examples |
|---------|---------|
| Supercomputer | PARAM (India), Fugaku (Japan) |
| Mainframe | IBM Z series |
| Minicomputer | PDP-11 |
| Microcomputer | Desktop, Laptop |

**India's first supercomputer:** PARAM 8000 (1991, C-DAC Pune)

### 4. Hardware Components

| Component | Function |
|-----------|----------|
| **CPU** | Brain of computer (processes instructions) |
| **ALU** | Arithmetic & Logic Unit (calculations) |
| **CU** | Control Unit (coordinates operations) |
| **RAM** | Primary memory, volatile, temporary storage |
| **ROM** | Read-Only Memory, non-volatile, permanent |
| **Hard Disk/SSD** | Secondary storage, permanent |
| **Monitor** | Output display |
| **Keyboard/Mouse** | Input devices |
| **Printer** | Output device |

**Memory Units:**
| Unit | Size |
|------|------|
| Bit | 0 or 1 |
| Byte | 8 bits |
| KB | 1024 Bytes |
| MB | 1024 KB |
| GB | 1024 MB |
| TB | 1024 GB |

### 5. Software

| Type | Examples |
|------|---------|
| **System Software** | Operating System (Windows, Linux, macOS) |
| **Application Software** | MS Word, Excel, Chrome |
| **Utility Software** | Antivirus, Disk Cleanup |

**Programming Languages:**
| Generation | Type | Example |
|-----------|------|---------|
| 1st | Machine Language | Binary (0,1) |
| 2nd | Assembly Language | Assembly code |
| 3rd | High-Level | C, C++, Java, Python |
| 4th | Very High-Level | SQL, MATLAB |
| 5th | AI Languages | Prolog, LISP |

### 6. Internet & Networking

| Term | Meaning |
|------|---------|
| Internet | Global network of networks |
| WWW | World Wide Web (invented by Tim Berners-Lee, 1989) |
| Browser | Software to access web (Chrome, Firefox) |
| URL | Uniform Resource Locator (web address) |
| HTTP/HTTPS | Protocol for web communication |
| Email | Electronic mail |
| IP Address | Unique identifier for devices on network |
| ISP | Internet Service Provider |

**Network Types:**
| Type | Range |
|------|-------|
| LAN | Local Area Network (building/campus) |
| MAN | Metropolitan Area Network (city) |
| WAN | Wide Area Network (country/world) |

**Network Topologies:** Star, Bus, Ring, Mesh, Tree
