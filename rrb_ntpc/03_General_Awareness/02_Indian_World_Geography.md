## 💡 Memory Tricks

1. **West-flowing rivers:** "NTS" — Narmada, Tapi, Sabarmati
2. **Peninsular river order (N to S):** "God Krishna Came" — Godavari, Krishna, Kaveri
3. **Continents by size:** "AAA NAES" — Asia, Africa, N.America, S.America, Antarctica, Europe, Australia (wrong but helpful pattern)
4. **Soil for cotton:** **Black** soil (think: Black → Dark → Cotton)
5. **Largest lake India:** "Wular" = Wonderful (freshwater), "Chilika" = Chilled (brackish/salty)

### PYQ 4: **Largest state by area?** → Rajasthan

### PYQ 6: **Chilika Lake is in which state?** → Odisha
### PYQ 7: **Highest dam in India?** → Tehri Dam
### PYQ 8: **Which pass connects Srinagar to Leh?** → Zoji La
### PYQ 9: **Deepest point of ocean?** → Mariana Trench (Pacific)
