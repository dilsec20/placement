## 📖 Complete Theory

### 1. What is Syllogism?
Syllogism involves drawing **logical conclusions** from two or more given **statements**, regardless of whether the statements are true in real life.

> ⚠️ **Golden Rule:** Accept the statements as TRUE even if they contradict reality.

### 2. Types of Statements

| Statement | Notation | Meaning | Venn Diagram |
|-----------|----------|---------|-------------|
| All A are B | Universal Affirmative | Every A is B | A inside B |
| No A is B | Universal Negative | Not a single A is B | A and B separate |
| Some A are B | Particular Affirmative | At least one A is B | A and B overlap |
| Some A are not B | Particular Negative | At least one A is not B | Part of A outside B |

### 3. Valid Conclusions (Rules)

#### From "All A are B":
- ✅ Some A are B (always true)
- ✅ Some B are A (always true)
- ❌ All B are A (NOT necessarily true)
- ❌ No A is B (false)

#### From "No A is B":
- ✅ No B is A (always true)
- ✅ Some A are not B (always true)
- ✅ Some B are not A (always true)
- ❌ All A are B (false)
- ❌ Some A are B (false)

#### From "Some A are B":
- ✅ Some B are A (always true — conversion)
- ❌ All A are B (not necessarily)
- ❌ No A is B (not necessarily)

#### From "Some A are not B":
- ❌ Some B are not A (NOT necessarily true!)
- ❌ No conversion is valid

### 4. Two-Statement Combinations

#### "All A are B" + "All B are C":
- ✅ All A are C
- ✅ Some C are A
- ✅ Some A are C

#### "All A are B" + "No B is C":
- ✅ No A is C
- ✅ No C is A
- ✅ Some A are not C

#### "All A are B" + "Some B are C":
- ❌ Some A are C (NOT definite — C might overlap with B outside A)

#### "Some A are B" + "All B are C":
- ✅ Some A are C

#### "Some A are B" + "No B is C":
- ✅ Some A are not C

#### "No A is B" + "All B are C":
- ❌ No definite conclusion about A and C

### 5. Possibility-Based Questions

**"Some A are B" → Is it POSSIBLE that "All A are B"?**
- ✅ YES — "Some" doesn't exclude "All"

**"No A is B" → Is it POSSIBLE that "Some A are B"?**
- ❌ NO — "No" means zero overlap

**General Rule for Possibility:**
- A definite "No" blocks possibility of overlap
- A definite "All" blocks possibility of "No"
- "Some" allows possibility of "All" or "Some not"

### 6. Complementary Pairs

| Statement | Complementary |
|-----------|--------------|
| All A are B | Some A are NOT B |
| Some A are B | No A is B |

In a complementary pair, **exactly one must be true**. This is useful when asked "Either conclusion I or II follows."

## 📐 Key Concepts & Methods

### Venn Diagram Method (MOST RELIABLE):

1. Draw Venn diagrams for all **possible** interpretations of the statements
2. Check if the conclusion holds in ALL possible diagrams
3. If it fails in even ONE diagram → conclusion does NOT follow

### Quick Decision Table:

| Statement 1 | Statement 2 | Valid Conclusion |
|-------------|-------------|-----------------|
| All A are B | All B are C | All A are C ✅ |
| All A are B | No B is C | No A is C ✅ |
| All A are B | Some B are C | No definite conclusion ❌ |
| Some A are B | All B are C | Some A are C ✅ |
| Some A are B | No B is C | Some A are not C ✅ |
| No A is B | All B are C | Some C are not A ✅ |
| No A is B | Some B are C | No definite conclusion about A and C ❌ |

---

## 💡 Tips & Shortcuts

### Tip 1: Draw Multiple Venn Diagrams
If "Some A are B" — draw both minimal overlap AND complete overlap to test conclusions.

### Tip 2: "Some" Does NOT Mean "Only Some"
"Some A are B" allows the possibility that ALL A are B.

### Tip 3: Complementary Pair = Either/Or
If I: "All A are B" and II: "Some A are not B" are given as conclusions → Either I or II ALWAYS follows.

### Tip 4: Start from the Common Term
In two statements, find the common (middle) term. Conclusions connect the other two terms.

### Tip 5: Negative + Negative = No Conclusion
If both statements are negative ("No A is B" + "No B is C"), no definite conclusion can be drawn.

## 📝 RRB NTPC Previous Year Questions (PYQs)

### PYQ 1 (RRB NTPC 2021)
**Statements: All dogs are cats. All cats are birds. Conclusions: I. All dogs are birds. II. Some birds are dogs.**
(A) Only I (B) Only II (C) Both (D) Neither
**Answer: (C) Both** → All A are B + All B are C → All A are C ✅ and Some C are A ✅

### PYQ 2 (RRB NTPC 2021)
**Statements: Some pens are erasers. All erasers are books. Conclusions: I. Some pens are books. II. All books are pens.**
(A) Only I (B) Only II (C) Both (D) Neither
**Answer: (A) Only I** → Some A are B + All B are C → Some A are C ✅. "All C are A" doesn't follow ❌.

### PYQ 3 (RRB NTPC 2021)
**Statements: No man is a donkey. All donkeys are animals. Conclusions: I. No man is an animal. II. Some animals are not men.**
(A) Only I (B) Only II (C) Both (D) Neither
**Answer: (B) Only II** → "No A is B + All B are C" → Some C are not A ✅. "No A is C" is not definite ❌.

### PYQ 4 (RRB NTPC 2019)
**Statements: All flowers are trees. No tree is a stone. Conclusions: I. No flower is a stone. II. Some stones are flowers.**
(A) Only I (B) Only II (C) Both (D) Neither
**Answer: (A) Only I** → All A are B + No B is C → No A is C ✅. "Some C are A" = false ❌.

### PYQ 5 (RRB NTPC 2021)
**Statements: Some teachers are doctors. All doctors are engineers. Conclusions: I. Some teachers are engineers. II. All engineers are teachers.**
(A) Only I (B) Only II (C) Both (D) Neither
**Answer: (A) Only I** → Some A are B + All B are C → Some A are C ✅.

### PYQ 6 (RRB NTPC 2021)
**Statements: All books are pens. All pens are chairs. Conclusions: I. All books are chairs. II. All chairs are books.**
(A) Only I (B) Only II (C) Both (D) Neither
**Answer: (A) Only I** → All A⊂B⊂C → All A are C ✅. All C are A ❌.

### PYQ 7 (RRB NTPC 2020)
**Statements: No car is bus. Some buses are trains. Conclusions: I. Some trains are not cars. II. No car is train.**
(A) Only I (B) Only II (C) Both (D) Neither
**Answer: (A) Only I** → The overlapping part of buses and trains is definitely not cars → Some trains are not cars ✅.

### PYQ 8 (RRB NTPC 2021)
**Statements: All roses are flowers. Some flowers are red. Conclusions: I. Some roses are red. II. Some red are flowers.**
(A) Only I (B) Only II (C) Both (D) Neither
**Answer: (B) Only II** → "Some flowers are red" → "Some red are flowers" ✅ (conversion). "Some roses are red" is not definite ❌.

## 🎯 Exam Strategy
1. **Venn diagram approach** is the safest — draw for every question
2. **Memorize the combination table** — saves time on common patterns
3. **Check "Either I or II" option** — test complementary pairs
4. **Accept absurd statements** — "All dogs are cats" must be taken as true
5. **Expected time:** 60–90 seconds
