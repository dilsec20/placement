## 📖 Complete Theory

### 🔷 SECTION 1: Algebraic Identities

Algebraic identities are equations that are true for all values of the variables. They are the most powerful tools for simplification.

---

#### 🔸 Identity 1: Square of a Sum
$$(a + b)^2 = a^2 + 2ab + b^2$$

**Example:** $(3x + 5)^2 = 9x^2 + 30x + 25$

**Derived results:**
- $a^2 + b^2 = (a + b)^2 - 2ab$
- $2ab = (a + b)^2 - a^2 - b^2$

---

#### 🔸 Identity 2: Square of a Difference
$$(a - b)^2 = a^2 - 2ab + b^2$$

**Example:** $(7 - 2x)^2 = 49 - 28x + 4x^2$

**Derived results:**
- $a^2 + b^2 = (a - b)^2 + 2ab$
- $(a + b)^2 - (a - b)^2 = 4ab$
- $(a + b)^2 + (a - b)^2 = 2(a^2 + b^2)$

---

#### 🔸 Identity 3: Difference of Squares
$$a^2 - b^2 = (a + b)(a - b)$$

**Example:** $49 - 25 = (7 + 5)(7 - 5) = 12 × 2 = 24$ ✓

**Application:** Quick multiplication!
- $103 × 97 = (100 + 3)(100 - 3) = 10000 - 9 = 9991$

---

#### 🔸 Identity 4: Cube of a Sum
$$(a + b)^3 = a^3 + b^3 + 3ab(a + b) = a^3 + 3a^2b + 3ab^2 + b^3$$

**Example:** $(2 + 3)^3 = 8 + 27 + 3(6)(5) = 8 + 27 + 90 = 125$ = $5^3$ ✓

---

#### 🔸 Identity 5: Cube of a Difference
$$(a - b)^3 = a^3 - b^3 - 3ab(a - b) = a^3 - 3a^2b + 3ab^2 - b^3$$

---

#### 🔸 Identity 6: Sum of Cubes
$$a^3 + b^3 = (a + b)(a^2 - ab + b^2)$$

**Also:** $a^3 + b^3 = (a + b)^3 - 3ab(a + b)$

---

#### 🔸 Identity 7: Difference of Cubes
$$a^3 - b^3 = (a - b)(a^2 + ab + b^2)$$

**Also:** $a^3 - b^3 = (a - b)^3 + 3ab(a - b)$

---

#### 🔸 Identity 8: Three-Variable Identity
$$(a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + bc + ca)$$

**Derived:**
- $a^2 + b^2 + c^2 = (a + b + c)^2 - 2(ab + bc + ca)$

---

#### 🔸 Identity 9: Sum of Three Cubes (Conditional)
$$\text{If } a + b + c = 0, \text{ then } a^3 + b^3 + c^3 = 3abc$$

**General form:**
$$a^3 + b^3 + c^3 - 3abc = (a + b + c)(a^2 + b^2 + c^2 - ab - bc - ca)$$

**Also:**
$$a^3 + b^3 + c^3 - 3abc = \frac{1}{2}(a + b + c)[(a-b)^2 + (b-c)^2 + (c-a)^2]$$

---

#### 🔸 Identity 10: Important Results for x + 1/x type

If $x + \frac{1}{x} = k$, then:

| Expression | Value |
|-----------|-------|
| $x^2 + \frac{1}{x^2}$ | $k^2 - 2$ |
| $x^2 - \frac{1}{x^2}$ | $k \cdot \sqrt{k^2 - 4}$ |
| $x - \frac{1}{x}$ | $\pm\sqrt{k^2 - 4}$ |
| $x^3 + \frac{1}{x^3}$ | $k^3 - 3k$ |
| $x^4 + \frac{1}{x^4}$ | $(k^2 - 2)^2 - 2$ |

If $x - \frac{1}{x} = k$, then:
| Expression | Value |
|-----------|-------|
| $x^2 + \frac{1}{x^2}$ | $k^2 + 2$ |
| $x^3 - \frac{1}{x^3}$ | $k^3 + 3k$ |

### 🔷 SECTION 2: Factorization

Factorization is the process of breaking an expression into a product of simpler expressions.

#### Methods of Factorization:

**Method 1: Common Factor**
- $6x^2 + 9x = 3x(2x + 3)$

**Method 2: Grouping**
- $ax + ay + bx + by = a(x + y) + b(x + y) = (a + b)(x + y)$

**Method 3: Using Identities**
- $x^2 - 9 = (x + 3)(x - 3)$ → [using $a^2 - b^2$]
- $x^2 + 6x + 9 = (x + 3)^2$ → [using $(a+b)^2$]
- $8x^3 + 27 = (2x)^3 + 3^3 = (2x + 3)(4x^2 - 6x + 9)$ → [using $a^3 + b^3$]

**Method 4: Splitting the Middle Term (for quadratics)**
- $x^2 + 5x + 6 = x^2 + 3x + 2x + 6 = x(x + 3) + 2(x + 3) = (x + 2)(x + 3)$

**Example:** Factorize $2x^2 + 7x + 3$
- Product = 2 × 3 = 6, Sum = 7 → numbers are 6 and 1
- $= 2x^2 + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3)$

### 🔷 SECTION 3: Linear Equations

#### Single Variable:
$ax + b = 0 \Rightarrow x = -b/a$

**Example:** $3x + 12 = 0 → x = -4$

#### Two Variables (Simultaneous):
$a_1x + b_1y = c_1$ ... (i)
$a_2x + b_2y = c_2$ ... (ii)

**Methods to solve:**
1. **Substitution Method:** Express one variable in terms of the other
2. **Elimination Method:** Multiply equations to eliminate one variable
3. **Cross-Multiplication Method:**

$$\frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}$$

**Example:** Solve: $2x + 3y = 12$ and $x - y = 1$

**Solution (Elimination):**
- From equation (ii): x = y + 1
- Substituting in (i): 2(y + 1) + 3y = 12 → 2y + 2 + 3y = 12 → 5y = 10 → y = 2
- x = 2 + 1 = 3
- **Solution: x = 3, y = 2**

#### Condition for Consistency:
| Condition | Type | Solutions |
|-----------|------|-----------|
| $\frac{a_1}{a_2} \neq \frac{b_1}{b_2}$ | Consistent (Unique) | Exactly one |
| $\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}$ | Dependent | Infinitely many |
| $\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}$ | Inconsistent | No solution |

### 🔷 SECTION 4: Quadratic Equations

**Standard Form:** $ax^2 + bx + c = 0$ where $a \neq 0$

#### Quadratic Formula:
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

#### Discriminant: $D = b^2 - 4ac$

| Discriminant | Nature of Roots |
|-------------|-----------------|
| D > 0 | Two distinct real roots |
| D = 0 | Two equal real roots |
| D < 0 | No real roots (complex) |
| D is a perfect square | Rational roots |
| D > 0, not perfect square | Irrational roots |

#### Sum and Product of Roots:
If α and β are roots of $ax^2 + bx + c = 0$:
- **Sum of roots:** α + β = −b/a
- **Product of roots:** α × β = c/a
- **Equation from roots:** $x^2 - (\alpha + \beta)x + \alpha\beta = 0$

**Example:** Find the sum and product of roots of $2x^2 - 5x + 3 = 0$

**Solution:**
- Sum = −(−5)/2 = 5/2
- Product = 3/2
- Verify: Roots are $x = \frac{5 ± \sqrt{25-24}}{4} = \frac{5 ± 1}{4}$ → x = 3/2 or x = 1 ✓
- Sum = 3/2 + 1 = 5/2 ✓, Product = 3/2 × 1 = 3/2 ✓

### 🔷 SECTION 5: Surds & Indices (Laws of Exponents)

#### Laws of Exponents (Indices):

| Law | Rule |
|-----|------|
| **Product Rule** | $a^m × a^n = a^{m+n}$ |
| **Quotient Rule** | $a^m ÷ a^n = a^{m-n}$ |
| **Power of Power** | $(a^m)^n = a^{mn}$ |
| **Power of Product** | $(ab)^n = a^n \cdot b^n$ |
| **Power of Quotient** | $(a/b)^n = a^n/b^n$ |
| **Zero Exponent** | $a^0 = 1$ (where $a \neq 0$) |
| **Negative Exponent** | $a^{-n} = 1/a^n$ |
| **Fractional Exponent** | $a^{1/n} = \sqrt[n]{a}$ |
| **General Fractional** | $a^{m/n} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$ |

**Example:** Simplify $\frac{2^5 \times 3^3 \times 2^{-2}}{3^2 \times 2^4}$

**Solution:**
- $= \frac{2^{5-2} \times 3^3}{3^2 \times 2^4} = \frac{2^3 \times 3^3}{3^2 \times 2^4} = 2^{3-4} \times 3^{3-2} = 2^{-1} \times 3 = \frac{3}{2}$

---

#### Surds:

A surd is an irrational root that cannot be simplified to a rational number. Example: √2, ∛5, √7

**Types of Surds:**
| Type | Example |
|------|---------|
| Pure Surd | √5, ∛7 |
| Mixed Surd | 3√2, 5∛3 |
| Like Surds | 2√3 and 5√3 |
| Unlike Surds | 2√3 and 5√2 |
| Compound Surd | (√3 + √5) |

**Rationalization:**
To rationalize a denominator with surds, multiply by the **conjugate**:
- Conjugate of (a + √b) is (a − √b)
- Conjugate of (√a + √b) is (√a − √b)

**Example:** Rationalize $\frac{1}{\sqrt{3} + \sqrt{2}}$

**Solution:**
$$= \frac{1}{\sqrt{3} + \sqrt{2}} \times \frac{\sqrt{3} - \sqrt{2}}{\sqrt{3} - \sqrt{2}} = \frac{\sqrt{3} - \sqrt{2}}{3 - 2} = \sqrt{3} - \sqrt{2}$$

**Example:** If $x = \frac{1}{3 - 2\sqrt{2}}$, find x.

**Solution:**
$$x = \frac{1}{3 - 2\sqrt{2}} \times \frac{3 + 2\sqrt{2}}{3 + 2\sqrt{2}} = \frac{3 + 2\sqrt{2}}{9 - 8} = 3 + 2\sqrt{2}$$

### 🔷 SECTION 6: Simplification (BODMAS)

**Order of Operations:** B → O → D → M → A → S
- **B** = Brackets: ( ), { }, [ ] — innermost first
- **O** = Orders: Powers, roots
- **D** = Division (left to right with M)
- **M** = Multiplication (left to right with D)
- **A** = Addition (left to right with S)
- **S** = Subtraction (left to right with A)

**Example:** Simplify $12 + 3 × (8 - 4)^2 ÷ 6$

**Solution:**
- = 12 + 3 × (4)² ÷ 6
- = 12 + 3 × 16 ÷ 6
- = 12 + 48 ÷ 6
- = 12 + 8
- = **20**

## 💡 Tips, Tricks & Shortcuts

### 🔹 Shortcut 1: Quick Squaring
- $(a + b)^2$ — use it for numbers near a round number
- $52^2 = (50 + 2)^2 = 2500 + 200 + 4 = 2704$
- $98^2 = (100 - 2)^2 = 10000 - 400 + 4 = 9604$

### 🔹 Shortcut 2: Difference of Squares for Multiplication
- $47 × 53 = (50 - 3)(50 + 3) = 2500 - 9 = 2491$
- $996 × 1004 = (1000 - 4)(1000 + 4) = 1000000 - 16 = 999984$

### 🔹 Shortcut 3: When a + b + c = 0
- Immediately conclude: $a^3 + b^3 + c^3 = 3abc$
- Very commonly asked in exams!

### 🔹 Shortcut 4: x + 1/x Chain
- If you know $x + 1/x$, you can find ANY power of $x + 1/x^n$ step by step
- First find $x^2 + 1/x^2$, then $x^3 + 1/x^3$, etc.

### 🔹 Shortcut 5: Finding Roots Quickly
- For $x^2 + bx + c = 0$ (when a = 1): find two numbers whose sum = −b and product = c

### 🔹 Shortcut 6: Rationalization Pattern
$$\frac{1}{\sqrt{a} + \sqrt{b}} = \frac{\sqrt{a} - \sqrt{b}}{a - b}$$

### 🔹 Shortcut 7: Exponent Comparison
- When $a^x = a^y$, then x = y (provided a ≠ 0, 1, −1)
- When $a^x = b^x$, then a = b (provided x ≠ 0)

### 🔹 Shortcut 8: Simplification Tricks
- When you see $a^2 + b^2 + 2ab$ → it's $(a+b)^2$
- When you see $a^2 + b^2 - 2ab$ → it's $(a-b)^2$
- When you see $a^2 - b^2$ → immediately factor as $(a+b)(a-b)$

### 🔹 Shortcut 9: Quadratic with Equal Roots
- If D = 0, both roots = $-b/(2a)$
- Sum of roots = $-b/a$, each root = $-b/(2a)$

### 🔹 Shortcut 10: Component and Dividendo
$$\text{If } \frac{a}{b} = \frac{c}{d}, \text{ then } \frac{a+b}{a-b} = \frac{c+d}{c-d}$$

## 📝 RRB NTPC Previous Year Questions (PYQs)

### Question 1
**If $x + \frac{1}{x} = 5$, find $x^2 + \frac{1}{x^2}$.**

(A) 21  
(B) 23  
(C) 25  
(D) 27  

**✅ Correct Answer: (B) 23**

**Solution:**
- $x^2 + \frac{1}{x^2} = \left(x + \frac{1}{x}\right)^2 - 2 = 25 - 2 = \textbf{23}$

---

### Question 2
**If $a + b + c = 0$, find the value of $\frac{a^3 + b^3 + c^3}{abc}$.**

(A) 0  
(B) 1  
(C) 3  
(D) −3  

**✅ Correct Answer: (C) 3**

**Solution:**
- When a + b + c = 0, $a^3 + b^3 + c^3 = 3abc$
- Therefore, $\frac{3abc}{abc} = \textbf{3}$

---

### Question 3
**Find the value of $105 × 95$.**

(A) 9975  
(B) 9995  
(C) 9925  
(D) 10025  

**✅ Correct Answer: (A) 9975**

**Solution:**
- $105 × 95 = (100 + 5)(100 - 5) = 100^2 - 5^2 = 10000 - 25 = \textbf{9975}$

---

### Question 4
**If $a - b = 3$ and $a^2 + b^2 = 29$, find the value of $ab$.**

(A) 10  
(B) 12  
(C) 15  
(D) 20  

**✅ Correct Answer: (A) 10**

**Solution:**
- $(a - b)^2 = a^2 - 2ab + b^2$
- $9 = 29 - 2ab$
- $2ab = 20$
- $ab = \textbf{10}$

---

### Question 5
**Solve: $2x + 3y = 12$ and $3x - 2y = 5$. Find $x + y$.**

(A) 3  
(B) 4  
(C) 5  
(D) 6  

**✅ Correct Answer: (C) 5**

**Solution:**
- Multiply eq(1) by 2: $4x + 6y = 24$
- Multiply eq(2) by 3: $9x - 6y = 15$
- Adding: $13x = 39 → x = 3$
- From eq(1): $6 + 3y = 12 → y = 2$
- $x + y = 3 + 2 = \textbf{5}$

---

### Question 6
**If $x^2 - 3x + 1 = 0$, find $x^3 + \frac{1}{x^3}$.**

(A) 18  
(B) 27  
(C) 9  
(D) 36  

**✅ Correct Answer: (A) 18**

**Solution:**
- $x^2 - 3x + 1 = 0$ → Dividing by x: $x - 3 + \frac{1}{x} = 0$ → $x + \frac{1}{x} = 3$
- $x^3 + \frac{1}{x^3} = \left(x + \frac{1}{x}\right)^3 - 3\left(x + \frac{1}{x}\right) = 27 - 9 = \textbf{18}$

### Question 7
**Find the value of $\frac{4.63 \times 4.63 - 3.37 \times 3.37}{4.63 - 3.37}$.**

(A) 6  
(B) 7  
(C) 8  
(D) 9  

**✅ Correct Answer: (C) 8**

**Solution:**
- $\frac{a^2 - b^2}{a - b} = \frac{(a+b)(a-b)}{(a-b)} = a + b$
- $= 4.63 + 3.37 = \textbf{8}$

### Question 8
**Simplify: $(2^3)^2 \times 2^{-4} \div 2^3$**

(A) 2  
(B) 4  
(C) 1/2  
(D) 1  

**✅ Correct Answer: (C) 1/2**

**Solution:**
- $= 2^6 \times 2^{-4} \div 2^3$
- $= 2^{6-4} \div 2^3$
- $= 2^2 \div 2^3$
- $= 2^{2-3} = 2^{-1} = \textbf{1/2}$

### Question 9
**If $\sqrt{x} + \frac{1}{\sqrt{x}} = 2\sqrt{3}$, find $x + \frac{1}{x}$.**

(A) 8  
(B) 10  
(C) 12  
(D) 14  

**✅ Correct Answer: (B) 10**

**Solution:**
- Squaring both sides: $x + 2 + \frac{1}{x} = 12$
- $x + \frac{1}{x} = 12 - 2 = \textbf{10}$

### Question 10
**If $a + b = 10$ and $ab = 21$, find $a^3 + b^3$.**

(A) 370  
(B) 440  
(C) 460  
(D) 500  

**✅ Correct Answer: (A) 370**

**Solution:**
- $a^3 + b^3 = (a+b)^3 - 3ab(a+b)$
- $= 1000 - 3(21)(10)$
- $= 1000 - 630 = \textbf{370}$

### Question 11
**The sum of roots of $3x^2 - 9x + 6 = 0$ is:**

(A) 2  
(B) 3  
(C) 6  
(D) 9  

**✅ Correct Answer: (B) 3**

**Solution:**
- Sum of roots = $-b/a = -(-9)/3 = 9/3 = \textbf{3}$

### Question 12
**Rationalize: $\frac{5}{\sqrt{7} - \sqrt{2}}$**

(A) $\sqrt{7} - \sqrt{2}$  
(B) $\sqrt{7} + \sqrt{2}$  
(C) $5(\sqrt{7} + \sqrt{2})$  
(D) $7 + 2$  

**✅ Correct Answer: (B) $\sqrt{7} + \sqrt{2}$**

**Solution:**
$$\frac{5}{\sqrt{7} - \sqrt{2}} \times \frac{\sqrt{7} + \sqrt{2}}{\sqrt{7} + \sqrt{2}} = \frac{5(\sqrt{7} + \sqrt{2})}{7 - 2} = \frac{5(\sqrt{7} + \sqrt{2})}{5} = \sqrt{7} + \sqrt{2}$$

---

### Question 13
**If $(a + b + c) = 6$ and $(a^2 + b^2 + c^2) = 14$, find $(ab + bc + ca)$.**

(A) 11  
(B) 13  
(C) 15  
(D) 17  

**✅ Correct Answer: (A) 11**

**Solution:**
- $(a+b+c)^2 = a^2 + b^2 + c^2 + 2(ab+bc+ca)$
- $36 = 14 + 2(ab+bc+ca)$
- $2(ab+bc+ca) = 22$
- $ab + bc + ca = \textbf{11}$

## 🎯 Exam Strategy & Revision Tips

### ✅ Do's:
1. **Master all 10 identities** — They appear in almost every exam
2. **Practice x + 1/x type problems** — Most frequently asked!
3. **Memorize the condition a + b + c = 0** → leads to $a^3 + b^3 + c^3 = 3abc$
4. **Know laws of exponents** by heart — practice simplification daily
5. **Learn to spot identity patterns** quickly in disguised questions
6. **Practice rationalization** with surds — common 1-mark questions

### ❌ Don'ts:
1. Don't solve quadratics by formula if factorization is easier
2. Don't forget: $(a-b)^2$ has ALL POSITIVE terms: $a^2 + b^2 - 2ab$
3. Don't confuse $(a+b)^3$ with $a^3 + b^3$ — they are different!
4. Don't skip BODMAS — even experienced students make errors

### 📅 Revision Schedule:
| Day | Activity |
|-----|----------|
| Day 1 | Memorize all identities + practice 10 problems |
| Day 2 | Factorization + linear equations — 15 problems |
| Day 3 | Quadratic equations + surds — 15 problems |
| Day 4 | x + 1/x type + simplification — 20 problems |
| Day 5 | Mixed practice + PYQs |

### 🏆 Time Management:
- **Identity-based** (direct formula): 20–30 seconds
- **Equation solving** (2 variables): 60–90 seconds
- **Complex simplification**: 90–120 seconds
- Skip if > 2 minutes — come back later

### 📌 Top 5 Must-Remember Things:
1. $x + 1/x = k$ → $x^2 + 1/x^2 = k^2 - 2$
2. $a + b + c = 0$ → $a^3 + b^3 + c^3 = 3abc$
3. $a^2 - b^2 = (a+b)(a-b)$ — use for quick multiplication
4. Sum of roots = $-b/a$, Product = $c/a$
5. Rationalize by multiplying with conjugate
