## 🎯 Role Breakdown: DevEx vs. Platform & Infrastructure

ACKO is a digital-first tech company where **the platform IS the business**. If the platform is down, customers cannot buy insurance or file claims.

| Dimension | Role 1: DevEx (Developer Operations & Experience) | Role 2: SR&I (Site Reliability & Infrastructure) |
|---|---|---|
| **Core Mission** | Build software, frameworks, and agentic tooling that sits between apps and infra so engineers ship code faster & safely. | Build and operate the cloud platform, Kubernetes clusters, and pipelines that power all of Acko with 99.99% reliability. |
| **Typical Problem** | Build a CI check that flags risky database migrations; create service templates with default logging/metrics. | Automate infra via Terraform; build Kubernetes operators; design disaster recovery drills & automated failure recovery. |
| **Core Stack** | Go, Python, Java, TypeScript, Git, Linux, CI/CD, LLM-based agent tooling, Docker. | AWS, GCP, Kubernetes, Terraform, Docker, Linux, Networking (TCP/IP, DNS, HTTP), Prometheus, Grafana. |
| **Key Mindset** | **User Empathy:** Treating internal software engineers as your customers. | **Automate & Measure:** "When you do something twice by hand, you automate it. Measure before optimizing." |
