  ├── Tasks: Find failed payments, identify root causes, discover API bugs, automate checks.

  ├── Deep Manual Testing Scenarios (Payment gateway, UPI checkout, OTP screens, Idempotency).
  ├── API Testing (Postman, REST Assured, JSON schema, Auth tokens, Status codes).
  ├── Automation Engineering (Selenium / Appium in Python, POM, Waits, iframes, handling flakiness).

     ▼ (Shortlist)

  ├── Production bug triage ("A payment bug escaped to production; what do you do?").

  └── Alignment with Juspay's engineering culture (Ownership, Systems Thinking, First-Principles).
     │
     ▼
